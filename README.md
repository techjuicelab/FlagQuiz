# 🌍 세계 국기 퀴즈 (FlagQuiz)

아이와 함께 세계 194개 나라의 **국기·수도·상징물·명소**를 놀이로 익히는 한국어 학습 게임입니다. 만 4~5세가 글자 없이 소리와 그림으로 혼자 놀 수 있게 만들었습니다.
브라우저에서 바로 놀 수 있어요. 한 번 캐시된 퀴즈는 오프라인에서도 이용할 수 있지만,
마이크 음성 인식에는 브라우저에 따라 인터넷 연결이 필요합니다.

### 👉 지금 바로 놀기: **https://techjuicelab.github.io/FlagQuiz/**

아이폰·아이패드에서는 이 주소를 **사파리로 연 뒤 공유 → 홈 화면에 추가** 하면
앱처럼 쓰고, 그다음부터는 인터넷 없이도 놀 수 있어요.

## 바로 시작하기

### 1) 가장 간단한 방법 — 파일 열기
`index.html` 파일을 더블클릭하면 바로 게임이 열립니다.
> 단, 이 방법에서는 **마이크로 말하기 모드**가 동작하지 않습니다(브라우저 보안 정책).
> 나머지 일곱 가지 모드는 모두 정상 동작합니다.

### 2) 말하기 모드까지 쓰려면 — 로컬 서버로 열기
Node.js가 설치돼 있다면:

```bash
npm start
# → 브라우저에서 http://localhost:8080 접속
```

포트를 바꾸고 싶다면 `npm start -- 3000`.

Node.js가 없다면 파이썬으로도 됩니다:

```bash
python3 -m http.server 8080
```

### 3) 인터넷에 올려서 쓰기
이미 배포되어 있습니다 → **https://techjuicelab.github.io/FlagQuiz/**

> 처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source** 를
> `GitHub Actions` 로 바꿔 주어야 합니다. 이 최초 설정만 저장소 관리자가 직접 해야 하고,
> 그다음부터는 `main` 에 올릴 때마다 `.github/workflows/pages.yml` 이 알아서 배포합니다.

### 4) 아이폰·아이패드에 앱처럼 설치하기 (추천)
`https` 주소(예: GitHub Pages)로 **사파리**에서 접속한 뒤,
아래쪽 **공유 버튼 → 홈 화면에 추가**를 누르면 앱 아이콘이 생기고
그다음부터는 **인터넷이 없어도** 놀 수 있습니다.

아이폰·아이패드에서 신경 쓴 점:

- 노치와 홈 인디케이터를 피해 화면 가장자리까지 안전하게 씁니다.
- 두 번 두드려도 확대되지 않고, 문제를 풀다가 글자가 끌려 선택되지 않습니다.
- 입력칸 글씨를 16px 이상으로 두어 답을 쓸 때 화면이 확대되지 않습니다.
- **아이패드 가로 화면과 아이폰 가로 화면**에서는 국기와 보기가 좌우로 나란히 놓여
  스크롤 없이 한눈에 보입니다.
- 아이폰 SE처럼 세로가 짧은 화면에서도 국기와 보기 네 개가 한 화면에 들어옵니다.
- 사파리는 손가락으로 화면을 만진 흐름 안에서만 소리를 열어 줍니다. 이 허가는 시간이
  지나거나 음성 인식이 소리 장치를 가져갔다 놓으면 풀리기 때문에, **손가락 조작이 있을
  때마다 읽어주기를 다시 깨웁니다.** (**측면 무음 스위치가 켜져 있으면 효과음이 나지 않습니다.**)
- 말하기 모드는 사파리에서 동작합니다. 소리가 안 잡히면
  *설정 → 일반 → 키보드 → 받아쓰기 활성화* 가 켜져 있는지 확인해 주세요.
  홈 화면에 추가한 앱에서 마이크가 막히면 사파리에서 열면 됩니다.

## 놀이 방법 아홉 가지

| 모드 | 이렇게 놀아요 |
| --- | --- |
| 🚩 **국기 보고 나라 고르기** | 국기를 보고 네 개의 나라 이름 중에서 고릅니다. 가장 기본이에요. |
| 🔎 **나라 보고 국기 찾기** | 나라 이름을 보고 국기 네 개 중에서 찾습니다. 반대 방향으로 기억이 굳어져요. |
| 🎤 **말로 답하기** | 마이크가 준비되어 **“듣고 있어요”**가 나오면 나라 이름을 끝까지 말해 주세요. 최종 인식 결과로 채점합니다. |
| ⌨️ **이름 써서 맞히기** | 나라 이름을 직접 입력합니다. 조금 틀리게 써도 알아줘요. |
| 🏙️ **수도 듣고 국기 찾기** | Sua가 읽어 주는 수도 이름을 듣고 국기 네 개 중에서 그 나라를 찾습니다(🔊 눌러서 들어보기). 힌트는 두 단계 — 한 번 누르면 오답 두 개를 지우고 수도를 다시 읽어 주고, 한 번 더 누르면 "○○의 수도예요"까지 읽어 줍니다(그렇게 맞힌 답은 기록에 '한 번 더 만날 나라'로 남아요). 기록은 국기 스티커와 따로 쌓여 도감 칸의 🏙️ 수도 도장이 됩니다. |
| 🎤 **국기 보고 수도 말하기** | 국기와 나라 이름을 보고 수도를 말합니다. 수도 이름과 몇 가지 다른 이름("워싱턴", "비엔나")을 알아듣고, 소리가 닮으면 인정해요. 힌트는 수도를 들려주는 것이라 듣고 따라 말하는 연습이 되고, 그렇게 맞힌 답은 '한 번 더 만날 나라'로 남습니다. 기록과 도장은 수도 듣기와 같아요. |
| 🗺️ **지도에서 나라 찾기** | 국기와 이름을 보고 국경선 없는 세계지도 위 핀 네 개 중에서 그 나라 자리를 고릅니다. |
| 🎨 **그림 보고 나라 고르기** | 나라를 떠올리는 그림(상징물) 한 장을 보고 국기 네 개 중에서 고릅니다. 그림 이름은 Sua가 읽어 줘요. |
| 🏞️ **명소 보고 나라 고르기** | 그 나라의 대표 명소 그림을 보고 국기 네 개 중에서 고릅니다. |

> 그림·명소·수도 놀이에서 **처음 만나는 나라**는 문제보다 먼저 **만나기 카드**가 나옵니다. 그림(수도 놀이는 국기)과 나라 이름을 보여 주고
> Sua가 나라 이름과 그림 이름(수도 놀이는 수도 이름과 "○○의 수도예요")을 읽어 준 뒤, 아이가 "문제 풀어 볼게요"를 누르면 같은 나라를 문제로 만납니다.
> 한 번 만난 나라는 다음부터 바로 문제로 나와요.

> **수도 놀이는 조금씩, 여러 번.** 한 판에 처음 만나는 나라는 세 개까지만(5문제 판은 두 개) 나오고, 나머지는 이미 만난 나라의 복습이에요.
> 새로 만난 나라는 같은 판에서 1문제 뒤와 3문제 뒤에 다시 나오고(복습할 나라가 없으면 판 끝에 한 번 더), 틀린 나라는 1문제 뒤에 한 번 더 나옵니다.
> 아직 안 굳은 나라가 많이 쌓이면 새 나라를 하나 줄여 복습을 늘려요.
> 보기 국기도 처음에는 다른 대륙 국기와 겨루다가, 익힐수록 같은 대륙, 같은 지역 국기로 좁아져요.
> 처음 만나는 나라는 서울·도쿄·베이징·파리·런던처럼 짧고 유명한 수도부터 나오고, 긴 이름은 맨 뒤에 나옵니다.
> 수도 안에 그 나라의 대표 명소가 있으면(서울 광화문, 파리 에펠탑, 런던 빅벤) 만나기 카드와 정답 카드에 그림을 같이 보여 줘요.
> 한 판이 끝나면 **오늘 만난 수도 다시 듣기**에서 국기마다 🔊를 누르거나 전부 이어 들을 수 있어요.

> **도장은 세 단계로 진해져요.** 한 번 맞히면 연한 도장, 다른 날에 또 맞히면 진한 도장, 다른 날에도 맞힌 뒤 세 번 연속 맞히면 반짝 도장이 됩니다.
> 예전에 찍은 도장은 그대로 연한 도장으로 남아요.

> **말하기 모드는 마이크를 계속 열어 둡니다.** "음…", "저기" 같은 말은 흘려듣고
> 나라 이름이 들릴 때만 채점하니, 편하게 이야기하면서 놀아도 됩니다.
>
> - **두 번 말해도, 앞뒤에 다른 말이 붙어도, 발음이 조금 틀려도 정답으로 인정합니다.**
>   "브라질 브라질", "음 그러니까 브라질이요", "브라찔" 모두 정답이에요.
> - **소리가 닮으면 인정하고, 긴 이름은 앞부분만 말해도 됩니다.** "캐냐"는 케냐, "구바"는 쿠바로 알아듣고,
>   "사우디아라", "오스트레일리"처럼 세 음절 이상을 말해 그 나라뿐이면 끝까지 말하지 않아도 정답이에요.
>   다른 나라 이름이 함께 들리면 인정하지 않습니다(니제르와 나이지리아는 여전히 다른 나라).
> - **말하자마자 채점합니다.** 나라 이름이 확실히 들리면 최종 결과를 기다리지 않아요.
>   인도·기니처럼 다른 나라 이름의 앞부분이 되는 이름만 끝까지 듣습니다.
> - **맞히면 설명을 듣고 저절로 다음 나라로 넘어갑니다.** 틀렸을 때는 답을 보고 "다음 나라"를 눌러요.
> - **모르겠다고 하거나 물어보면** — "몰라요", "이게 뭐야?", "어느 나라야?" —
>   나라 이름을 **한 번 읽고, 국기의 특징을 쉬운 한 문장으로 알려 줍니다.**
> - 잠깐 멈추고 싶으면 마이크 단추를 누르면 됩니다.
> - 정상 종료한 인식기는 재사용합니다. 권한 요청 여부는 브라우저·운영체제 설정에 따릅니다.
> - 연결 실패가 반복되면 마이크를 눌러 다시 시도하거나 글자로 답할 수 있습니다.
> - 다른 탭이나 앱으로 이동하면 마이크와 제한 시간을 멈춥니다. 돌아온 뒤 마이크를 눌러 다시 시작하세요.

## 게임처럼 모으는 재미

- **레벨과 경험치** — 맞힐 때마다 경험치가 오르고, 연속으로 맞히면 더 받습니다.
  🌱 씨앗 탐험가 → 🌿 새싹 탐험가 → 🧭 나침반 탐험가 → 🗺️ 지도 박사 → 🌍 세계 박사
- **스티커 판 194칸** — 나라를 처음 맞히면 그 나라 스티커를 얻습니다.
  아직 못 모은 칸은 자물쇠로 보이고, 모은 칸은 반짝입니다.
- **깜짝 상자** — 정답·다른 답·모르겠어요 모두 여행책에 한 장씩 쌓이고, 지난 상자 뒤 두 장째부터는 문제마다 15% 확률로 깜짝 상자가 나옵니다(여덟 장 안에는 반드시, 평균 5.5장에 한 번). 상자 모양은 방금 만난 나라의 대륙을 따르고(🏮 연등·🎁 리본 상자·🥁 북·🎈 풍선·🪅 피냐타·🐚 조개) 셋 중 하나를 골라 열며, 가끔은 한 번 더 두드려야 열립니다. 보통 상자(보너스 5점·경험치 20) 75%, 반짝 상자(경험치 40) 20%, 황금 상자(보너스 10점·경험치 60) 5%이고 빈 상자는 없습니다.
  **누적 다섯 장마다** 상자가 열리고 보너스 5점과 경험치 20을 받습니다. 다음 판에도 이어집니다.
- **오늘의 도전** — 날마다 대륙 하나가 정해지고, 그 대륙 나라 5개를 맞히면 끝납니다.
- **여행 마침** — 한 판을 마치면 여행을 마친 화면을 보여 주고, 점수와 정답률은 학습 기록에서 확인합니다.

## 함께 놀기 좋은 기능

- **둘이서 대결** — 이름을 두 개 넣으면 한 문제씩 번갈아 풀고, 마지막에 승자가 나옵니다.
- **제한 시간은 국기 놀이에만** — 그림·명소·지도·수도 놀이는 아이가 처음 보는 것이라 초시계를 붙이지 않습니다. 명소 정답 카드와 도감에는 '🏙️ 수도 · ○○의 수도예요' 한 줄과 듣기 단추가 있습니다.
- **난이도 3단계** — *쉬움*(잘 알려진 나라) → *보통* → *어려움*(194개국 전부).
- **대륙 골라 배우기** — 아시아만, 유럽만처럼 한 대륙씩 집중해서 익힐 수 있어요.
- **틀린 나라 더 자주** — 틀렸던 국기가 더 자주 출제되고, 두 번 연속 맞히면 빈도가 줄어듭니다.
- **한 번 더 만나기** — 홈 화면에서 다시 살펴볼 나라만 모아 풀 수 있어요.
- **함께 발견하는 배움 카드** — 어떤 답을 골라도 같은 부드러운 카드와 짧은 발견음을 사용합니다.
  "여행책에 한 장", "지도에 톡"처럼 반응이 바뀌고, 나라 이름 한 번과 쉬운 설명 한 문장을 Sua가 읽습니다.
  **🔊 다시 들려주기** 단추로 몇 번이든 다시 들을 수 있습니다.
  아이폰·아이패드가 소리를 막았을 때는 이 단추가 **주황색으로 커지며 "눌러서 들어보기"** 로 바뀝니다.
- **읽어주기** — 미리 생성한 Typecast Sua 음성으로 이름과 설명을 들려줍니다.
- **설명 다시 듣기** — 정답·오답의 배움 카드와 스티커 판에서 국기 설명·상식을 다시 들을 수 있습니다.
- **같이 보기** — 점수 차감 없이 국기 생김새와 첫 소리를 알려줍니다. 사지선다에서는 보기 두 개를 지워 줘요.
- **새 음악 16종** — 상자·발견·스티커·시작·마침에 MLX Core로 만든 짧은 음악을 사용합니다.
  배경 음악과 정답 전용 음악은 홈에서 켤 수 있고, 처음에는 꺼져 있습니다.
- **스티커 판** — 194개국을 검색하고 하나씩 자세히 볼 수 있는 사전이자 수집 판.
- **내 기록과 배지** — 만난 나라 수, 정답률, 자주 틀리는 국기, 그리고 16개의 배지.

키보드로도 놀 수 있어요. `1`~`4` 로 보기를 고르고, `Enter` 로 다음 문제로 넘어갑니다.

## 알아두면 좋은 점

- **퀴즈 기록은 이 브라우저 안에만** 저장됩니다(`localStorage`). 마이크 음성은 브라우저의 음성 인식 제공업체로 전달될 수 있습니다.
- 말하기 모드는 크롬·엣지·사파리에서 동작하며, `https` 주소나 `localhost` 가 필요합니다.
- 파이어폭스는 음성 인식을 지원하지 않아 말하기 모드 대신 **이름 써서 맞히기**를 이용해 주세요.
- 나라 목록은 **유엔 회원국 193개국에 바티칸을 더한 194개**입니다.
  국가로 볼지 견해가 갈리는 지역(대만, 팔레스타인, 코소보, 서사하라 등)과
  다른 나라에 속한 자치지역·속령(홍콩, 푸에르토리코, 그린란드 등)은 넣지 않았습니다.
  아이가 배우는 자료라 어른들 사이에서도 답이 갈리는 것은 빼는 편이 낫다고 보았습니다.
  지도에서는 **땅만 그리고 국경선을 나라를 가르는 선으로 쓰지 않습니다.** 어느 선을 어디에 긋느냐가 어른들 사이에서도 갈리는 문제라, 바다와 땅만 구분되는 한 장의 실루엣으로 그리고 나라는 어디서나 같은 크기의 핀으로 표시합니다.

## Sua 음성

나라·수도 이름, 국기 설명·상식, 정답·응원 메시지 977개(2026-09-10)에 상징물·명소 이름 342개(2026-09-17)를 더한
1,319개 문구(19,546자)를 Typecast Sua로 생성했습니다. 설정은 `data/voice-config.json`, 음원과 생성 이력은
`audio/sua/`에 보관합니다. 생성 요청 전체와 파일의 SHA-256을 확인하므로 완료된 음원은
다시 요청하지 않고 이어서 생성할 수 있습니다.
`js/voice-manifest.js`의 `ready`는 전체 문구의 파일·해시 검증이 끝나야 true가 됩니다.
전체 준비가 끝나면 미리 생성한 Sua 음원을 사용하고, 한번 받은 음원은 오프라인 캐시에 보관합니다.
파일이나 재생 권한에 문제가 있으면 다시 듣기 안내를 표시합니다.

```bash
npm run voice:plan       # 문구 목록과 누락 현황 갱신 (키 불필요)
npm run voice:sample     # 정답·응원·대한민국·국기 설명 4개 생성 (본 생성에서도 재사용)
npm run voice:check      # 누락이 있으면 종료 코드 1
npm run voice:generate   # 1Password → Typecast API, 제공 여부와 크레딧 확인 후 생성
```

두 API 키는 `env/typecast.op.env`의 `op://` 참조만 보관하고 브라우저나 음원 목록에 넣지 않습니다.
샘플 생성은 `api_key_2`를 사용합니다. 전체 생성은 각각의 제공 목소리·모델과 잔여 크레딧을
확인해 두 키에 나눕니다. 웹 플랜의 크레딧과 API 크레딧은 별도입니다.
`npm test`로 동작을 검사하고 `npm run build`로 음원 누락을 확인한 뒤 배포 파일을 `_site/`에 만듭니다.
배포에는 앱과 음원만 포함하며 생성 도구·원장·1Password 참조·로컬 점검 자료는 포함하지 않습니다.

## MLX Core 음악

MLX Core의 ACE-Step 1.5 XL Turbo (8-bit)로 16종을 직접 생성했습니다.
앱용 MP3는 `audio/music/`에 있으며 모두 합쳐 약 1 MB입니다. 상자 음악 6종은 바로 전 곡을 피해 고릅니다.
음악과 Sua 설명은 순서대로 재생하고, 마이크 사용·화면 이동 시 음악을 멈춥니다.

[제작 설정과 프롬프트 16종](docs/mlx-audio/README.md)에 재생성 방법과 편집·검증 기록을 정리했습니다.
원본 WAV는 로컬 `docs/artifacts/mlx-music/raw/`에 보존합니다.
