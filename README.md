# 🌍 세계 국기 퀴즈 (FlagQuiz)

아이와 함께 세계 194개 나라의 **국기·수도·상징물·명소**를 놀이로 익히는 한국어 학습 게임입니다. 만 4~5세가 글자 없이 소리와 그림으로 혼자 놀 수 있게 만들었습니다.
비공개 버전은 [NAS 주소](https://flagquiz.techjuicelab.space)에서 **나라 이름 번갈아 말하기**, TechJuice ID 로그인과 서버를 통한 음성 인식을 제공합니다. **국기 보고 나라 말하기·국기 보고 수도 말하기·나라 이어 말하기**는 모두 같은 NAS Groq STT 경로를 사용합니다. 기존 활성 TechJuice ID 계정에 세계 놀이 권한을 부여했으며 최고 관리자는 `TECHJUICELAB@gmail.com`입니다. 중앙 계정의 아이디 또는 이메일·비밀번호로 로그인하며 Google 로그인은 현재 비활성화되어 있습니다. [말하기 설계](docs/spoken-stt.md), [문장에서 최종 답 찾기](docs/spoken-answer-intent.md), [가족 인증 설계](docs/private-country-chain.md), [서버 실행 안내](server/README.md), [NAS 배포 검증 기록](docs/nas-deploy.md)을 참고하세요.

기존 공개 버전은 **설정 → 오프라인 저장 → 전체 저장하기**로 그림과 음성까지 준비하면 오프라인에서도 이용할 수 있었습니다. 현재 GitHub Pages는 NAS 진입과 이전 기록 이동 화면을 제공합니다. 아래 오프라인 안내는 기존 버전의 동작 기록이며, 보호된 NAS 서버는 앱 파일을 로그인 뒤에서 제공하고 오프라인 앱 복사본을 저장하지 않습니다.

## 바로 시작하기

### 1) TechJuice ID 가족용 서버
Node.js 24 이상과 1Password의 TechJuice ID·음성 API 설정이 필요합니다. [서버 실행 안내](server/README.md)에 따라 설정 후 `npm run build`와 `npm run start:private`를 실행하세요. 파일을 직접 열거나 정적 호스팅만으로 실행하면 로그인 서비스를 이용할 수 없습니다.

### 2) 게임 화면을 개발 미리보기로 열기
Node.js가 설치돼 있다면:

```bash
npm start
# → 브라우저에서 http://localhost:8080/?preview=1 접속
```

포트를 바꾸고 싶다면 `npm start -- 3000`.

개발 미리보기는 localhost에서만 열리고 TechJuice ID 로그인과 Groq STT를 연결하지 않습니다. 나라·수도 말하기와 나라 이어 말하기는 글자 입력으로 검토할 수 있습니다. 실제 음성 인식 검사는 로그인한 비공개 서버에서 진행합니다.

### 3) 인터넷에 올려서 쓰기
운영 앱은 [NAS 주소](https://flagquiz.techjuicelab.space)에서 이용합니다. [이전 GitHub Pages 주소](https://techjuicelab.github.io/FlagQuiz/)는 NAS 진입 화면을 제공하며 같은 기기의 기존 기록을 전달합니다.

운영 앱은 Forgejo `techjuice/flagquiz`의 `main`에 올리면 `.forgejo/workflows/deploy.yml`이 검사·이미지 빌드·NAS 배포를 수행합니다. 배포 설정과 실패 복귀 절차는 [NAS 안내](docs/nas-deploy.md)에 있습니다. `.github/workflows/pages.yml`은 별도의 이전 주소 진입 화면을 배포합니다.

### 4) 아이폰·아이패드에 앱처럼 설치하기 (추천)
운영 NAS 주소로 **사파리**에서 접속한 뒤,
아래쪽 **공유 버튼 → 홈 화면에 추가**를 누르면 앱 아이콘이 생기고
로그인 후 앱처럼 이용할 수 있습니다.

### 5) 기존 공개 버전의 오프라인 준비 안내

아래는 이전 공개 버전의 동작 기록입니다. 보호된 NAS 앱은 이 오프라인 복사본을 제공하지 않습니다.

1. 인터넷에 연결된 상태에서 앱을 열고, **설정 → 오프라인 저장**을 엽니다. 홈 아래 **인터넷 없이 놀기**를 눌러도 같은 곳으로 이동합니다.
2. **전체 저장하기**를 누릅니다. 국기 194장, 그림 342장, Sua 음성 1,319개와 음악 16개를 저장합니다(전체 약 155MB, Wi-Fi 권장).
3. **준비 완료**가 나올 때까지 앱을 열어 둡니다. 저장하는 동안 퀴즈를 풀어도 됩니다.
4. 이제 비행기 모드에서도 앱을 다시 열고 그림·지도·읽어주기를 이용할 수 있습니다. 지도 공부와 지도 퀴즈는 저장한 지도 자료로 그리므로, 외부 지도 서비스에 접속할 필요가 없습니다.

- 도중에 끊기면 받은 자료를 유지합니다. 같은 화면에서 연결이 돌아오면 나머지를 자동으로 이어받고, 앱을 닫았다면 다시 열어 저장 단추를 누르면 됩니다.
- 말하기 도중 연결이 끊기면 **같은 문제와 점수**를 유지하며 이름을 듣고 국기 네 개 중 고르는 방식으로 바뀝니다. 연결이 돌아오면 다음 문제부터 원래 말하기로 돌아갑니다.
- 저장하지 못한 그림은 **다음 그림**으로 점수 차감 없이 넘길 수 있습니다. 음성 파일을 받지 못해도 오래 기다리지 않게 합니다.
- 준비 상태는 실제 저장된 파일을 검사합니다. 브라우저의 사이트 데이터 삭제나 기기 저장 공간 정리로 자료가 사라지면 다시 저장해 주세요. 홈 화면 앱과 일반 브라우저는 저장 공간이 다를 수 있어, 실제 사용할 앱에서 준비 완료를 확인하세요.

아이폰·아이패드에서 신경 쓴 점:

- 노치와 홈 인디케이터를 피해 화면 가장자리까지 안전하게 씁니다.
- 두 번 두드려도 확대되지 않고, 문제를 풀다가 글자가 끌려 선택되지 않습니다.
- 입력칸 글씨를 16px 이상으로 두어 답을 쓸 때 화면이 확대되지 않습니다.
- 화면이 충분히 넓으면 문제와 보기를 좌우로 배치합니다. 지도 퀴즈는 지도를 크게 볼 수 있도록 항상 전체 폭을 쓰고, 질문과 국기는 위에 짧게 표시합니다. 좁은 iPad 분할 화면에서는 한 열로 돌아갑니다.
- 작은 화면이나 큰 글자 설정에서는 내용을 자르지 않고 스크롤할 수 있습니다.
- 사파리는 손가락으로 화면을 만진 흐름 안에서만 소리를 열어 줍니다. 이 허가는 시간이
  지나거나 음성 인식이 소리 장치를 가져갔다 놓으면 풀리기 때문에, **손가락 조작이 있을
  때마다 읽어주기를 다시 깨웁니다.** (**측면 무음 스위치가 켜져 있으면 효과음이 나지 않습니다.**)
- 운영 앱의 말하기는 **인터넷 연결·로그인·마이크 허용**이 필요합니다. 주소별 마이크 권한을 확인한 뒤 마이크 단추로 다시 시도하거나 같은 문제에 글자로 답할 수 있습니다. 홈 화면 앱에서 마이크를 열지 못하면 사파리에서 같은 NAS 주소를 열어 확인해 주세요.

## 퀴즈 아홉 가지와 그림·명소·지도·수도 공부

홈의 **나라 이름 번갈아 말하기**는 질문 없이 두 사람이 아직 나오지 않은 나라를 말하는 별도 놀이입니다. 일본 → 대한민국 → 중국 → 포르투갈처럼 차례대로 기록하고 국기·지도 위치를 함께 표시합니다. 한국/대한민국처럼 다른 이름이어도 같은 나라로 처리하며, 중복·모르는 이름·여러 나라를 한꺼번에 말한 경우에는 현재 차례에서 다시 말합니다. 좁은 화면의 누적 지도는 좌우로 움직일 수 있고, 선택한 나라 위치가 보이도록 이동합니다. 지도나 아래 나라 목록을 누르면 해당 나라 정보를 다시 볼 수 있습니다. **새로 하기**나 화면을 떠나면 새 판으로 시작하며, 이 놀이의 발화 기록은 현재 판의 메모리에만 유지합니다.

보호된 서버에서는 기존 TechJuice ID 계정으로 로그인합니다. **가족 계정**의 SuperAdmin 화면에서 앱 접근을 관리할 수 있습니다. 마이크를 한 번 켜면 현재 차례의 발화를 받아 나라 이름을 읽은 뒤 상대 차례의 듣기를 이어갑니다. 자동 화자 구분은 사용하지 않습니다. 인식 연결이 실패하면 같은 차례·기록을 유지한 채 글자로 입력할 수 있습니다.

**놀이** 홈에는 국기·그림·지도·수도 네 주제가 있습니다. **그림 놀이**에서 그림 또는 명소를 고르면 각각 **공부하기 / 퀴즈 풀기**가 나옵니다. 지도와 수도도 공부·퀴즈를 따로 선택합니다. **도감 / 기록**은 폰 하단, 넓은 iPad에서는 왼쪽에서 이동합니다.

**설정**은 한 번 탭하면 열립니다. 이름·놀이 조건·소리 변경은 즉시 저장되고, 기록 내보내기·가져오기와 초기화도 여기서 할 수 있습니다. 기록 교체와 초기화 직전에는 확인창이 나옵니다. 이전 주소의 기록은 새 주소에 기록이 없으면 자동으로 이어지며, 이미 기록이 있으면 원하는 기록을 고릅니다. 교체 전 기록은 백업 다운로드로 보관할 수 있습니다.

홈에서 **수도 놀이**를 누르면 **수도 공부**와 **수도 퀴즈**를 고를 수 있어요.
수도 공부는 점수 없이 듣고 넘기는 별도 화면이고, 수도 퀴즈는 아래의 두 방식으로 바로 문제를 풉니다.
홈에서 **지도 놀이**를 누르면 **지도 공부**와 **지도 퀴즈**를 고를 수 있어요.
지도 공부는 세계에서의 위치와 주변 확대 지도를 살펴보는 별도 화면이고, 지도 퀴즈는 공부 화면을 거치지 않고 문제부터 시작합니다.
홈에서 **그림 놀이**를 누른 뒤 **그림** 또는 **명소**를 고르세요. 선택한 소재의 **공부하기**는 그림·나라 이름을 보고 들어보며 넘기고, **퀴즈 풀기**는 국기 네 개 중 정답을 바로 고릅니다.
퀴즈 모드는 모두 아홉 가지이며, 공부 화면은 퀴즈 모드 수에 포함하지 않습니다.

| 모드 | 이렇게 놀아요 |
| --- | --- |
| 🚩 **국기 보고 나라 고르기** | 국기를 보고 네 개의 나라 이름 중에서 고릅니다. 가장 기본이에요. |
| 🔎 **나라 보고 국기 찾기** | 나라 이름을 보고 국기 네 개 중에서 찾습니다. 반대 방향으로 기억이 굳어져요. |
| 🎤 **말로 답하기** | 마이크가 준비되어 **“듣고 있어요”**가 나오면 나라 이름을 끝까지 말해 주세요. 잠깐 조용해지면 녹음을 마치고 NAS의 STT가 확인한 최종 문자로 채점합니다. |
| ⌨️ **이름 써서 맞히기** | 나라 이름을 직접 입력합니다. 조금 틀리게 써도 알아줘요. |
| 🏙️ **수도 듣고 국기 찾기** | Sua가 읽어 주는 수도 이름을 듣고 국기 네 개 중에서 그 나라를 찾습니다(🔊 눌러서 들어보기). 힌트는 두 단계 — 한 번 누르면 오답 두 개를 지우고 수도를 다시 읽어 주고, 한 번 더 누르면 "○○의 수도예요"까지 읽어 줍니다(그렇게 맞힌 답은 기록에 '한 번 더 만날 나라'로 남아요). 기록은 국기 스티커와 따로 쌓여 도감 칸의 🏙️ 수도 도장이 됩니다. |
| 🎤 **국기 보고 수도 말하기** | 국기와 나라 이름을 보고 수도를 말합니다. NAS의 STT로 받은 최종 문자를 수도 이름과 다른 이름("워싱턴", "비엔나")으로 판정해요. 힌트는 수도를 들려주는 것이라 듣고 따라 말하는 연습이 되고, 그렇게 맞힌 답은 '한 번 더 만날 나라'로 남습니다. 기록과 도장은 수도 듣기와 같아요. |
| 🗺️ **지도에서 나라 찾기** | 국기와 이름을 보고, 대륙 이름이 적힌 세계지도 위 번호 네 개 중에서 나라의 위치를 고릅니다. 작은 점이 실제 대표 좌표이고 번호는 그 위에 표시됩니다. 좁은 화면에서는 **지도 확대**를 누르고 좌우로 움직여 볼 수 있습니다. 답을 고른 뒤에는 세계 위치와 주변 확대 지도를 함께 살펴봅니다. |
| 🎨 **그림 보고 나라 고르기** | 나라를 떠올리는 그림(상징물) 한 장을 보고 국기 네 개 중에서 고릅니다. 정답이 드러나지 않는 그림 이름은 Sua가 읽어 줘요. |
| 🏞️ **명소 보고 나라 고르기** | 그 나라의 대표 명소 그림을 보고 국기 네 개 중에서 고릅니다. |

> **그림·명소 공부는 문제와 별도로 진행해요.** 선택한 소재의 그림·나라·그림 이름과 짧은 나라 설명을 보고 듣고, 이전·다음으로 내 속도에 맞게 넘깁니다.
> 설정한 난이도·대륙·개수만큼 살펴본 뒤에는 다른 그림을 계속 공부하거나 메뉴로 돌아갈 수 있어요. 공부 중에는 정오답·점수·보상 기록이 바뀌지 않고 퀴즈가 자동으로 시작되지 않습니다.
> **그림·명소 퀴즈는 바로 문제를 풀어요.** 처음 보는 나라에도 만나기 카드를 끼우지 않습니다.

> **지도 공부는 위치를 먼저 알아봐요.** 국기·나라 이름·대륙·지역을 보고, 세계지도에서 어느 대륙에 있는지 확인합니다.
> 세계지도의 테두리 안을 **주변 확대 지도**에서 크게 볼 수 있어요. 작은 점과 나라 이름이 대표 위치를 가리키며, 점의 크기는 나라의 면적이나 국경을 뜻하지 않습니다.
> **이전 나라 · 다음 나라 · 나라 설명 듣기**로 살펴보고, 점수·정오답 기록·도장에는 영향을 주지 않아요.
> 설정한 범위만큼 공부한 뒤에는 다른 나라를 계속 공부하거나 지도 놀이로 돌아갑니다. 공부 뒤 퀴즈가 자동으로 시작되지는 않아요.
> **지도 퀴즈는 같은 판 안에서 서로 다른 나라를 냅니다.** 후보가 설정한 문제 수보다 적으면 그 수만큼만 풉니다.

> **수도 공부는 내 속도로 넘겨요.** 큰 수도 이름과 국기를 보면서 "서울", "대한민국의 수도예요"를 듣습니다.
> **이전 수도 · 다음 수도 · 다시 듣기**로 편하게 살펴보고, 점수·정오답 기록·도장에는 영향을 주지 않아요.
> 설정한 난이도·대륙·개수만큼 공부한 뒤에는 **다른 수도 공부하기**, **퀴즈 고르기**, **홈으로** 중에서 직접 고릅니다.
> 같은 앱을 열어 둔 동안 공부를 이어가면 아직 안 본 수도부터 보여 줍니다. 공부 뒤 퀴즈가 자동으로 시작되지는 않아요.

> **수도 퀴즈는 서로 다른 문제만 풀어요.** **듣고 국기 고르기** 또는 **말로 답하기**를 고르면 만나기 카드 없이 바로 시작합니다.
> 설정한 범위에서 고른 문제 수만큼 서로 다른 수도를 내며, 후보가 적으면 그 수만큼만 풉니다.
> 틀리거나 힌트를 써도 같은 판에 다시 나오지 않고, 결과의 **한 번 더 만날 나라**에 남겨 나중에 복습할 수 있어요.
> 보기 국기는 처음에는 다른 대륙 국기부터, 익힐수록 같은 대륙·같은 지역 국기로 좁아집니다.

> **수도 놀이의 주인공은 수도 이름이에요.** 공부·문제·정답 카드의 **수도 명패**에 수도 이름이 가장 큰 글자로 나옵니다.
> 공부·정답 카드에서는 그 아래 국기와 "**대한민국**의 수도예요" 한 줄이 붙고, 수도 안에 대표 명소가 있으면 명패 안에 그림도 보여 줘요.
> 수도 말하기 문제에서는 이름 자리가 물음표이고, 힌트로 수도를 들려줄 때 이름이 뜹니다.
> 퀴즈가 끝나면 **오늘 만난 수도 다시 듣기**에서 국기마다 🔊를 누르거나 전부 이어 들을 수 있어요.
> **수도 다시 공부하기**를 누르면 이번 판에서 만난 나라만 다시 살펴봐요. 공부에는 채점·점수·보상이 없습니다.
> 이름 힌트로 답을 들은 경우에는 결과와 최근 놀이에서 **직접 맞힌 나라 / 답을 듣고 맞힌 나라**를 구분합니다. 성공 점수는 받지만, 누적 정답률은 직접 맞힌 답만 정답으로 셉니다. 답을 들은 문제도 푼 문제 수에는 포함되며, 도장을 찍지 않고 한 번 더 공부할 나라에 남겨요.

> **도장은 세 단계로 진해져요.** 한 번 맞히면 연한 도장, 다른 날에 또 맞히면 진한 도장, 다른 날에도 맞힌 뒤 세 번 연속 맞히면 반짝 도장이 됩니다.
> 예전에 찍은 도장은 그대로 연한 도장으로 남아요.

> **말하기 모드는 한 답씩 녹음하고 문장에서 최종으로 고른 이름을 판정합니다.** "듣고 있어요"가 나오면 나라 또는 수도 이름을 끝까지 말하세요. 잠깐 조용해지면 녹음을 마치고 답을 확인한다는 안내를 표시합니다. 확인 중에는 새 녹음을 시작하지 않습니다.
>
> - "뭐지… 스페인 아니고 포르투갈"은 **포르투갈**, 반대로 "포르투갈 아니고 스페인"은 **스페인**을 답으로 받습니다. 문제 정답을 단서로 아이의 선택을 바꾸지 않습니다. "포르투갈인지 스페인인지"처럼 답을 고르지 않은 경우에는 같은 문제에서 하나만 다시 말하도록 안내합니다.
> - STT가 받은 문장에서 이름·별칭·조사·정정 표현으로 최종 답을 고른 뒤 기존 채점 규칙에 전달합니다. "브라질 브라질", "음 그러니까 브라질이요"도 하나의 답이며 "브라찔" 같은 짧은 단독 발음은 전체 나라에서 유일한 후보일 때만 보완합니다. 실제 어린이 목소리가 늘 그 문자로 인식된다는 보장은 별도 기기 검사로 확인해야 합니다.
> - "캐냐"는 케냐, "구바"는 쿠바로 판정하고, "사우디아라", "오스트레일리"처럼 다른 이름과 혼동되지 않는 긴 이름의 일부도 인정합니다. 인도와 인도네시아처럼 다른 나라로 이어질 수 있는 중간 발화는 먼저 채점하지 않습니다.
> - **국기·지도·그림·명소·수도 퀴즈에서 정답을 맞히면 다음 문제로 자동으로 넘어갑니다.** 정답 이름을 한 번 더 짧게 들려주고, 읽어주기를 끈 경우에도 잠깐 뒤 진행해요. 더 긴 설명은 정답 카드의 다시 듣기로 들을 수 있어요. 선물은 문제 위의 작은 알림으로 바로 보여 주며 확인할 필요가 없습니다. 마지막 문제라면 결과 화면으로 갑니다. 오답은 답을 보고 "다음 나라"를 눌러요.
> - **모르겠다고 하거나 물어보면** — "몰라요", "이게 뭐야?", "어느 나라야?" —
>   나라 이름을 **한 번 읽고, 국기의 특징을 쉬운 한 문장으로 알려 줍니다.**
> - 잠깐 멈추고 싶으면 마이크 단추를 누르면 됩니다. 권한 요청 여부는 브라우저·운영체제 설정에 따릅니다.
> - 무음·권한·연결·사용량 오류는 **같은 문제와 차례**를 유지합니다. 글자로 답하거나 마이크를 눌러 다시 시도할 수 있으며 실패한 유료 요청을 자동으로 반복하지 않습니다.
> - 제한시간을 켠 경우 **마이크 권한·녹음 정리·STT 응답 대기 시간은 빼고 실제 녹음 시간을 셉니다.** 같은 문제에서 글자로 답하거나 수동 재시도를 기다릴 때는 기존 제한시간이 이어집니다.
> - 다른 탭이나 앱으로 이동하면 마이크와 제한 시간을 멈춥니다. 돌아온 뒤 마이크를 눌러 다시 시작하세요.

최초 NAS 운영 배포의 로그인·외부 HTTPS·실제 Groq 전사·백업·재시작 검증은 [배포 기록](docs/nas-deploy.md)에 있습니다. 이번 모든 말하기 경로 통합의 운영 반영과 iPhone/iPad에서 실제 어린이 발화 정확도·지연은 별도 검증 대상입니다.

## 게임처럼 모으는 재미

- **레벨과 경험치** — 맞힐 때마다 경험치가 오르고, 연속으로 맞히면 더 받습니다.
  🌱 씨앗 탐험가 → 🌿 새싹 탐험가 → 🧭 나침반 탐험가 → 🗺️ 지도 박사 → 🌍 세계 박사
- **스티커 판 194칸** — 나라를 처음 맞히면 그 나라 스티커를 얻습니다.
  아직 못 모은 칸은 자물쇠로 보이고, 모은 칸은 반짝입니다.
- **깜짝 상자** — 정답·다른 답·모르겠어요 모두 여행책에 한 장씩 쌓이고, 지난 상자 뒤 두 장째부터는 문제마다 15% 확률로 깜짝 상자가 나옵니다(여덟 장 안에는 반드시, 평균 5.5장에 한 번). 선물·보너스 점수·경험치는 즉시 저장하고 문제 위의 작은 알림으로 보여 줍니다. 알림은 화면이나 답 버튼을 덮지 않고 자동으로 사라지며, 문제 진행이나 읽어주기를 기다리게 하지 않습니다. 보통 상자(보너스 5점·경험치 20) 75%, 반짝 상자(경험치 40) 20%, 황금 상자(보너스 10점·경험치 60) 5%이고 빈 상자는 없습니다.
- **그림 선물 27개** — 선물 보상이 나오면 소방차·공룡 장난감·로켓 등 27가지 중 아직 모으지 않은 그림 선물을 즉시 받습니다. 작은 선물 알림은 별도 확인이나 상자 열기 없이 보여 줍니다. 모두 모은 뒤에는 이미 받은 선물을 다시 만나요. 받은 선물은 도감의 **내 그림 선물**에서 볼 수 있고, 여행 결과와 기록 백업에도 들어갑니다. 앱 안에서 모으는 그림이며 실제 물건을 지급하지는 않습니다.
- **오늘의 도전** — 날마다 대륙 하나가 정해지고, 그 대륙 나라 5개를 맞히면 끝납니다.
- **여행 마침** — 한 판을 마치면 여행을 마친 화면을 보여 주고, 점수와 정답률은 학습 기록에서 확인합니다.

## 함께 놀기 좋은 기능

- **둘이서 대결** — 이름을 두 개 넣으면 한 문제씩 번갈아 풀고, 마지막에 승자가 나옵니다.
- **제한 시간은 국기 놀이에만** — 그림·명소·지도·수도 놀이는 아이가 처음 보는 것이라 초시계를 붙이지 않습니다. 명소 정답 카드와 도감에는 '🏙️ 수도 · ○○의 수도예요' 한 줄과 듣기 단추가 있습니다.
- **난이도 3단계** — *쉬움*(잘 알려진 나라) → *보통* → *어려움*(194개국 전부).
- **대륙 골라 배우기** — 아시아만, 유럽만처럼 한 대륙씩 집중해서 익힐 수 있어요.
- **틀린 나라 더 자주** — 틀렸던 국기가 더 자주 출제되고, 두 번 연속 맞히면 빈도가 줄어듭니다.
- **한 번 더 만나기** — **국기 놀이 → 한 번 더 만나기**에서 다시 살펴볼 나라만 모아 풀 수 있어요.
- **함께 발견하는 배움 카드** — 어떤 답을 골라도 같은 부드러운 카드와 짧은 발견음을 사용합니다.
  "여행책에 한 장", "지도에 톡"처럼 반응이 바뀌고, 나라 이름 한 번과 쉬운 설명 한 문장을 Sua가 읽습니다.
  **🔊 다시 들려주기** 단추로 몇 번이든 다시 들을 수 있습니다.
  아이폰·아이패드가 소리를 막았을 때는 이 단추가 **주황색으로 커지며 "눌러서 들어보기"** 로 바뀝니다.
- **읽어주기** — 미리 생성한 Typecast Sua 음성으로 이름과 설명을 들려줍니다. 꺼 두면 수도 문제나 오프라인 전환의 자동 안내도 설정을 다시 켜지 않습니다. 직접 듣기 단추를 누르면 읽어주기를 켜고 들을 수 있어요.
- **설명 다시 듣기** — 정답·오답의 배움 카드와 스티커 판에서 국기 설명·상식을 다시 들을 수 있습니다.
- **같이 보기** — 점수 차감 없이 국기 생김새와 첫 소리를 알려줍니다. 사지선다에서는 보기 두 개를 지워 줘요.
- **새 음악 16종** — 상자·발견·스티커·시작·마침에 MLX Core로 만든 짧은 음악을 사용합니다.
  배경 음악과 정답 전용 음악은 **설정 → 소리**에서 켤 수 있고, 처음에는 꺼져 있습니다.
  정답 전용 음악은 맞힌 이름과 함께 짧게 재생하며, 음악이 끝나기를 기다리지 않고 다음 문제로 넘어갑니다.
- **스티커 판** — 194개국을 검색하고 하나씩 자세히 볼 수 있는 사전이자 수집 판.
- **내 기록과 배지** — 만난 나라 수, 정답률, 자주 틀리는 국기, 그리고 16개의 배지.
  ‘목소리 탐험가’는 국기 말하기에서 실제 음성으로 맞혔을 때 받습니다. 터치·글자 대체 입력으로는 지급하지 않으며, 새 놀이·배지 날짜는 기기의 오늘 날짜로 기록합니다. 기존 기록과 받은 배지는 보존합니다.

키보드로도 놀 수 있어요. `1`~`4` 로 보기를 고르고, `Enter` 로 다음 문제로 넘어갑니다.

```
│   ├── screens.js        국기 도감 / 내 기록 화면
│   ├── offline.js        전체 오프라인 저장·진행률·재연결 시 이어받기
│   └── app.js            홈·퀴즈·결과 화면과 흐름
├── sw.js                 오프라인 캐시 (셸·국기·그림·음원 버킷)
├── scripts/serve.mjs     의존성 없는 로컬 서버 (그 밖의 scripts/ 는 자료·그림·음원 제작 도구)
└── tests/                자료·엔진·화면 검사 (npm test)
```

194개국 자료가 온전한지, 국기 파일이 다 있는지, 그리고 **말로 답할 때 채점이 새지 않는지**를 확인합니다.

- 지도 좌표 194개가 나라 목록과 정확히 짝지는지 — 빠진 나라도, 목록에서 뺀 나라의 좌표가 남은 것도 없는지
- 아이가 말한 그대로 인정하는지 — 두 번 말하기, 앞뒤에 붙는 말, 조사, 틀린 발음, 끊어 말한 이름
- 다른 나라 이름을 정답으로 잘못 인정하지 않는지 —
  니제르 ↔ 나이지리아, 오스트리아 ↔ 오스트레일리아, 슬로바키아 ↔ 슬로베니아,
  인도 ↔ 인도네시아, 아일랜드 ↔ 아이슬란드, 기니 ↔ 기니비사우 ↔ 적도기니
- 마이크에 들어온 평소 말이 나라 이름으로 잡히지 않는지 — "아 맞다", "또 할래", "하나만 더" 등
- STT가 로마자를 섞어 적은 문자도 판정하는지 — `Siri야` → 시리아는 문자 판정 예이며 실제 기기 인식 검사가 아닙니다.

## 알아두면 좋은 점

- **퀴즈 기록은 이 브라우저 안에만** 저장됩니다(`localStorage`). 말하기 녹음은 브라우저에서 NAS 서버를 거쳐 Groq로 전송하고, 앱의 디스크·학습 기록에는 저장하지 않습니다. API 키는 서버에서만 사용합니다.
- 말하기에는 로그인·인터넷과 `https` 주소의 마이크 녹음 기능이 필요합니다. 브라우저의 `getUserMedia`·`MediaRecorder`·오디오 변환 지원을 검사하며, 사용하지 못하면 같은 문제에서 글자로 답할 수 있습니다.
- 정적 개발 미리보기에서는 STT API가 연결되지 않습니다. 기존 브라우저 `SpeechRecognition`이나 iOS 키보드 받아쓰기 설정은 새 STT 경로에서 사용하지 않습니다.
- 나라 목록은 **유엔 회원국 193개국에 바티칸을 더한 194개**입니다.
  국가로 볼지 견해가 갈리는 지역(대만, 팔레스타인, 코소보, 서사하라 등)과
  다른 나라에 속한 자치지역·속령(홍콩, 푸에르토리코, 그린란드 등)은 넣지 않았습니다.
  아이가 배우는 자료라 어른들 사이에서도 답이 갈리는 것은 빼는 편이 낫다고 보았습니다.
  지도에서는 **땅만 그리고 국경선을 나라를 가르는 선으로 쓰지 않습니다.** 어느 선을 어디에 긋느냐가 어른들 사이에서도 갈리는 문제라, 바다와 땅만 구분되는 한 장의 실루엣으로 그리고 나라는 어디서나 같은 크기의 핀으로 표시합니다.

## Sua 음성

나라·수도 이름, 국기 설명·상식, 정답·응원 메시지 977개(2026-09-10)에 상징물·명소 이름 342개(2026-09-17)를 더한
1,319개 문구(19,546자)를 Typecast Sua로 생성했습니다. 설정은 `data/voice-config.json`, 음원과 생성 이력은
`audio/sua/`에 보관합니다. 생성 요청 전체와 파일의 SHA-256을 확인하므로 완료된 음원은
다시 요청하지 않고 이어서 생성할 수 있습니다.
`js/voice-manifest.js`의 `ready`는 전체 문구의 파일·해시 검증이 끝나야 true가 됩니다.
전체 준비가 끝나면 미리 생성한 Sua 음원을 사용합니다. 오프라인 캐시에 저장하는 기능과
**설정 → 오프라인 저장 → 전체 저장하기**는 개발 미리보기·기존 공개 버전의 기능이며 보호된 NAS 앱에서는 제공하지 않습니다.
파일이나 재생 권한에 문제가 있으면 다시 듣기 안내를 표시합니다.

```bash
npm run voice:plan       # 문구 목록과 누락 현황 갱신 (키 불필요)
npm run voice:sample     # 정답·응원·대한민국·국기 설명 4개 생성 (본 생성에서도 재사용)
npm run voice:check      # 누락이 있으면 종료 코드 1
npm run voice:generate   # 1Password → Typecast API, 제공 여부와 크레딧 확인 후 생성
```

두 API 키는 `env/typecast.op.env`의 `op://` 참조만 보관하고 브라우저나 음원 목록에 넣지 않습니다.
샘플 생성은 `api_key_2`를 사용합니다. 전체 생성은 각각의 제공 목소리·모델과 잔여 크레딧을
확인해 두 키에 나눕니다. 웹 플랜의 크레딧과 API 크레딧은 별도입니다.
`npm test`로 동작을 검사하고 `npm run build`로 음원 누락을 확인한 뒤 배포 파일을 `_site/`에 만듭니다.
배포에는 앱과 음원만 포함하며 생성 도구·원장·1Password 참조·로컬 점검 자료는 포함하지 않습니다.
빌드는 화면·스크립트·자료의 내용으로 서비스 워커의 셸 버전을 자동 계산합니다. 새 셸 설치가
완료되어야 이전 셸을 정리하며, 이미 저장한 음원 캐시(`flagquiz-v4`)는 업데이트 후에도 유지합니다.

MLX Core의 ACE-Step 1.5 XL Turbo (8-bit)로 16종을 직접 생성했습니다.
