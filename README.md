# 🌍 세계 국기 퀴즈 (FlagQuiz)

아이와 함께 세계 194개 나라의 **국기와 나라 이름**을 놀이로 익히는 한국어 학습 게임입니다.
설치할 것도, 인터넷 연결도 필요 없습니다. 브라우저만 있으면 바로 놀 수 있어요.

### 👉 지금 바로 놀기: **https://techjuicelab.github.io/FlagQuiz/**

아이폰·아이패드에서는 이 주소를 **사파리로 연 뒤 공유 → 홈 화면에 추가** 하면
앱처럼 쓰고, 그다음부터는 인터넷 없이도 놀 수 있어요.

![모드](https://img.shields.io/badge/모드-5가지-4f7cff) ![나라](https://img.shields.io/badge/나라-194개국-16a34a) ![의존성](https://img.shields.io/badge/외부_라이브러리-없음-ffb703)

## 바로 시작하기

### 1) 가장 간단한 방법 — 파일 열기
`index.html` 파일을 더블클릭하면 바로 게임이 열립니다.
> 단, 이 방법에서는 **마이크로 말하기 모드**가 동작하지 않습니다(브라우저 보안 정책).
> 나머지 네 가지 모드는 모두 정상 동작합니다.

### 2) 말하기 모드까지 쓰려면 — 로컬 서버로 열기
Node.js가 설치돼 있다면:

```bash
npm start
# → 브라우저에서 http://localhost:8080 접속
```

포트를 바꾸고 싶다면 `npm start -- 3000`.

Node.js가 없다면 파이썬으로도 됩니다:

```bash
python3 -m http.server 8080
```

### 3) 인터넷에 올려서 쓰기
이미 배포되어 있습니다 → **https://techjuicelab.github.io/FlagQuiz/**

> 처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source** 를
> `GitHub Actions` 로 바꿔 주어야 합니다. 이 최초 설정만 저장소 관리자가 직접 해야 하고,
> 그다음부터는 `main` 에 올릴 때마다 `.github/workflows/pages.yml` 이 알아서 배포합니다.

### 4) 아이폰·아이패드에 앱처럼 설치하기 (추천)
`https` 주소(예: GitHub Pages)로 **사파리**에서 접속한 뒤,
아래쪽 **공유 버튼 → 홈 화면에 추가**를 누르면 앱 아이콘이 생기고
그다음부터는 **인터넷이 없어도** 놀 수 있습니다.

아이폰·아이패드에서 신경 쓴 점:

- 노치와 홈 인디케이터를 피해 화면 가장자리까지 안전하게 씁니다.
- 두 번 두드려도 확대되지 않고, 문제를 풀다가 글자가 끌려 선택되지 않습니다.
- 입력칸 글씨를 16px 이상으로 두어 답을 쓸 때 화면이 확대되지 않습니다.
- **아이패드 가로 화면과 아이폰 가로 화면**에서는 국기와 보기가 좌우로 나란히 놓여
  스크롤 없이 한눈에 보입니다.
- 아이폰 SE처럼 세로가 짧은 화면에서도 국기와 보기 네 개가 한 화면에 들어옵니다.
- 사파리는 손가락으로 화면을 만진 흐름 안에서만 소리를 열어 줍니다. 이 허가는 시간이
  지나거나 음성 인식이 소리 장치를 가져갔다 놓으면 풀리기 때문에, **손가락 조작이 있을
  때마다 읽어주기를 다시 깨웁니다.** (**측면 무음 스위치가 켜져 있으면 효과음이 나지 않습니다.**)
- 말하기 모드는 사파리에서 동작합니다. 소리가 안 잡히면
  *설정 → 일반 → 키보드 → 받아쓰기 활성화* 가 켜져 있는지 확인해 주세요.
  홈 화면에 추가한 앱에서 마이크가 막히면 사파리에서 열면 됩니다.

## 놀이 방법 다섯 가지

| 모드 | 이렇게 놀아요 |
| --- | --- |
| 🚩 **국기 보고 나라 고르기** | 국기를 보고 네 개의 나라 이름 중에서 고릅니다. 가장 기본이에요. |
| 🔎 **나라 보고 국기 찾기** | 나라 이름을 보고 국기 네 개 중에서 찾습니다. 반대 방향으로 기억이 굳어져요. |
| 🎤 **말로 답하기** | **버튼을 누를 필요 없어요.** 국기가 나오면 바로 나라 이름을 말하면 알아듣습니다. 글자를 아직 못 써도 놀 수 있어요. |
| ⌨️ **이름 써서 맞히기** | 나라 이름을 직접 입력합니다. 조금 틀리게 써도 알아줘요. |
| 🏙️ **수도 맞히기** | 나라 이름을 보고 수도를 고릅니다. 나라를 한 걸음 더 깊이 알게 돼요. |

> **말하기 모드는 마이크를 계속 열어 둡니다.** "음…", "저기" 같은 말은 흘려듣고
> 나라 이름이 들릴 때만 채점하니, 편하게 이야기하면서 놀아도 됩니다.
>
> - **두 번 말해도, 앞뒤에 다른 말이 붙어도, 발음이 조금 틀려도 정답으로 인정합니다.**
>   "브라질 브라질", "음 그러니까 브라질이요", "브라찔" 모두 정답이에요.
> - **모르겠다고 하거나 물어보면** — "몰라요", "이게 뭐야?", "어느 나라야?" —
>   나라 이름을 **두 번 읽어 주고 국기의 특징을 짧게 알려 줍니다.** 다음엔 맞힐 수 있게요.
> - 잠깐 멈추고 싶으면 마이크 단추를 누르면 됩니다.
> - **마이크 허용은 처음 한 번만** 하면 됩니다. 인식기를 한 번만 만들어 두고 계속 다시 쓰기 때문에
>   문제가 넘어갈 때마다 다시 물어보지 않습니다.

## 함께 놀기 좋은 기능

- **둘이서 대결** — 이름을 두 개 넣으면 한 문제씩 번갈아 풀고, 마지막에 승자가 나옵니다.
- **난이도 3단계** — *쉬움*(잘 알려진 나라) → *보통* → *어려움*(194개국 전부).
- **대륙 골라 배우기** — 아시아만, 유럽만처럼 한 대륙씩 집중해서 익힐 수 있어요.
- **틀린 나라 더 자주** — 틀렸던 국기가 더 자주 출제되고, 두 번 연속 맞히면 빈도가 줄어듭니다.
- **오답노트 복습** — 홈 화면에서 틀렸던 나라만 모아 다시 풀 수 있어요.
- **정답 뒤 배움 카드** — 수도, 대륙, 그리고 아이가 좋아할 한 줄 상식을 함께 보여줍니다.
- **정답 축하** — 맞히면 화면 한가운데에 커다란 도장이 팡 튀어나오고, 금빛 빛살과 색종이가
  퍼지면서 **팡파레가 울리고 "정답!" 하고 목소리로도 칭찬해 줍니다.**
  **연속으로 맞힐수록 소리도 화면도 더 화려해져요**(3·5·7연속에서 한 단계씩).
- **못 맞혔을 때 외우기 도움** — 나라 이름을 두 번 보여 주고 읽어 준 뒤,
  국기의 특징을 한 줄로 알려 줍니다. 다음에 같은 국기가 나오면 떠올릴 수 있게요.
  **🔊 다시 들려주기** 단추로 몇 번이든 다시 들을 수 있습니다.
  아이폰·아이패드가 소리를 막았을 때는 이 단추가 **주황색으로 커지며 "눌러서 들어보기"** 로 바뀝니다.
- **읽어주기** — 나라 이름을 소리로 들려줍니다(브라우저 음성 합성).
- **힌트** — 국기 생김새 설명과 첫 소리를 알려줍니다. 사지선다에서는 오답 두 개를 지워 줘요.
- **국기 도감** — 194개국을 검색하고 하나씩 자세히 볼 수 있는 사전.
- **내 기록과 배지** — 만난 나라 수, 정답률, 자주 틀리는 국기, 그리고 16개의 배지.

키보드로도 놀 수 있어요. `1`~`4` 로 보기를 고르고, `Enter` 로 다음 문제로 넘어갑니다.

## 폴더 구조

```
FlagQuiz/
├── index.html            게임 화면 뼈대
├── css/style.css         스타일 (밝은 화면·어두운 화면 모두 지원)
├── data/countries.js     194개국 자료 (한글 이름, 별칭, 수도, 대륙, 난이도, 상식, 국기 힌트)
├── flags/                국기 SVG 194개
├── js/
│   ├── util.js           한글 자모 비교 등 순수 함수
│   ├── storage.js        브라우저 저장소 (설정·기록·오답노트·배지)
│   ├── audio.js          효과음(Web Audio)과 읽어주기(Speech Synthesis)
│   ├── speech.js         말하기 인식 (Web Speech API, ko-KR)
│   ├── effects.js        색종이 효과
│   ├── ui.js             화면 공통 도구
│   ├── quiz.js           출제·채점 엔진 (화면과 분리돼 있어 그대로 검사 가능)
│   ├── badges.js         배지 규칙
│   ├── screens.js        국기 도감 / 내 기록 화면
│   └── app.js            홈·퀴즈·결과 화면과 흐름
├── scripts/serve.mjs     의존성 없는 로컬 서버
└── tests/run.mjs         자료·엔진 검사 (npm test)
```

## 검사하기

```bash
npm test
```

194개국 자료가 온전한지, 국기 파일이 다 있는지, 그리고 **말로 답할 때 채점이 새지 않는지**를 확인합니다.

- 아이가 말한 그대로 인정하는지 — 두 번 말하기, 앞뒤에 붙는 말, 조사, 틀린 발음, 끊어 말한 이름
- 다른 나라 이름을 정답으로 잘못 인정하지 않는지 —
  니제르 ↔ 나이지리아, 오스트리아 ↔ 오스트레일리아, 슬로바키아 ↔ 슬로베니아,
  인도 ↔ 인도네시아, 아일랜드 ↔ 아이슬란드, 기니 ↔ 기니비사우 ↔ 적도기니
- 마이크에 들어온 평소 말이 나라 이름으로 잡히지 않는지 — "아 맞다", "또 할래", "하나만 더" 등
- 받아쓰기가 로마자로 적어 보낸 답도 인정하는지 — 아이패드의 `Siri야` → 시리아

## 알아두면 좋은 점

- **기록은 이 브라우저 안에만** 저장됩니다(`localStorage`). 서버로 보내는 정보가 하나도 없어요.
- 말하기 모드는 크롬·엣지·사파리에서 동작하며, `https` 주소나 `localhost` 가 필요합니다.
- 파이어폭스는 음성 인식을 지원하지 않아 말하기 모드 대신 **이름 써서 맞히기**를 이용해 주세요.
- 나라 목록은 **유엔 회원국 193개국에 바티칸을 더한 194개**입니다.
  국가로 볼지 견해가 갈리는 지역(대만, 팔레스타인, 코소보, 서사하라 등)과
  다른 나라에 속한 자치지역·속령(홍콩, 푸에르토리코, 그린란드 등)은 넣지 않았습니다.
  아이가 배우는 자료라 어른들 사이에서도 답이 갈리는 것은 빼는 편이 낫다고 보았습니다.
