## 실루엣과 빌드 게이트

- 모든 feature의 최대 링과 핀을 포함한 링을 보호한다. 좌표를 생성하지 않는 배제 지역 48개도 육지이므로 최대 링을 보존한다. 나머지 작은 부속 섬에는 기존 크기 필터를 적용한다.
- 반올림 뒤 면적이 0인 보호 링은 원본 bbox를 바깥쪽 0.1 격자로 감싼 사각형으로 대체한다. 최소 폭·높이는 0.1이다. 비보호 퇴화 링은 출력하지 않는다.
- 화면 변환 후 모든 외곽의 방향을 통일하고 양수 면적을 검사한다. 모든 bbox 대체 feature와 국가·배제 지역의 양수 면적 출력 여부를 확인한다.
- **파일을 쓰기 전에 최종 SVG 문자열을 다시 읽어 모든 핀의 winding number가 0이 아닌지 검사한다.** 실패하면 throw하고 기존 생성물을 덮어쓰지 않는다.
- `reduceArc`의 캐시 키는 `[...keys].reverse()`로 만든다.
- 원자료 없는 `npm run map:build`는 종료 코드 1과 함께 아래 메시지를 낸다.

```text
지도 원자료가 없습니다. npm run map:fetch 를 먼저 실행하세요.
```
