# FlagQuiz 확장 진행 상태

갱신: **2026-09-25**. 아래는 현재 상태이며, 이전 단계별 보고는 Git 이력과 [기존 검증 기록](verification/)에 보존된다.

## 현재 구현 상태

- **자료와 모드.** 그림 342/342(상징물 194·명소 148, 기니 젬베 북 포함), 수아 음원 1,319문구(상징물·명소 이름 342개 포함), 퀴즈 모드 9개와 별도 수도 공부 화면. main 변경은 GitHub Pages 워크플로에서 테스트·빌드 후 공개하며, 커밋별 배포 결과는 Actions 기록을 따른다.
- **아이 기준 화면.** 홈은 놀이 단추 4개(국기·그림·지도·수도)뿐이고 어른 설정은 '아빠 설정' 길게 누르기 뒤에 있다. 문제 화면은 글자 대신 🔊 와 국기 보기가 주인공, 처음 만나는 그림·명소는 만나기 카드가 먼저이고, 수도 공부는 별도 화면에서 진행한다. 지도는 폰 세로 확대·아이패드 가로 2열·세로 한 줄. 시안 원본은 `design/kid-ux-2026-09-17/`.
- **수도 공부와 퀴즈 분리(D30, 2026-09-25).** 홈의 수도 놀이에서 '수도 공부'와 '수도 퀴즈'를 선택한다. 공부는 난이도·대륙·개수 설정을 따르는 국기·수도 카드에 이전·다음·다시 듣기를 제공하며, 점수·정오답 기록·도장에 영향을 주지 않는다. 끝나면 다른 수도 공부·퀴즈 선택·홈 중에서 고르고 퀴즈로 자동 전환하지 않는다. 같은 앱 세션에서 다시 공부하면 아직 공부하지 않은 수도부터 보여 준다.
- **수도 퀴즈는 중복 없는 문제만.** '듣고 국기 고르기'(`capital`)와 '말로 답하기'(`capitalVoice`) 모두 만나기 카드 없이 바로 시작한다. 설정 범위 전체에서 선택한 문제 수만큼 서로 다른 나라를 뽑고, 후보가 적으면 판을 줄인다. D24의 새 나라 2~3개 한도·같은 판 반복·오답 재삽입과 D27의 고정 소개 순서는 제거했다. 틀리거나 힌트로 답을 알아도 같은 판에서 다시 내지 않으며 결과의 복습 목록에 남긴다. 그림·명소·지도는 기존 D15를 유지한다.
- **수도 기록과 도움.** 기록은 `axes.capital`, 도감의 🏙️ 수도 도장과 도장 3단계(D26)는 유지한다. 보기 국기는 익힌 정도에 따라 다른 대륙 → 같은 대륙 → 같은 지역으로 좁힌다. 힌트로 답까지 들은 정답은 점수를 주되 기록에는 '아직'으로 남긴다. 수도 말하기는 수도 이름으로 채점하며, 결과의 '오늘 만난 수도 다시 듣기'와 이어 듣기도 유지한다. 사파리의 외국 지명 인식은 실기기 확인이 필요하다.
- **수도 명패(D29).** 공부·문제·정답 카드에서 수도 이름이 가장 큰 글자이며, 공부·정답 카드에는 그 아래 국기와 '○○의 수도예요'를 둔다. 수도 안 명소 그림은 명패 안에 표시한다. 수도 말하기 문제는 물음표로 시작하고 힌트 때 이름을 보여 준다. 명소 정답 카드·도감의 수도 듣기 한 줄(D1 후속)도 유지한다.
- **말로 답하기(D25, 2026-09-18).** 목표 나라는 소리 닮은꼴('캐냐'→케냐)과 세 음절 이상 앞부분('사우디아라')도 인정하되 다른 나라 이름이 걸리면 안 함(194개국 전수 교차 검사). 확실한 중간 결과는 바로 채점(인도·기니만 끝까지 듣기). 맞히면 설명 뒤 0.9초에 저절로 다음(틀림·상자·낭독 실패는 수동).
- **엔진.** 그림·명소·지도는 자기 기록 가중치 + 한 판 안 3문제 뒤 다시 만나기(D15). 제한 시간은 국기 놀이에만(D23). 미채점 지나감은 기록·정답률·배지·차례 어디에도 안 들어감(D20).
- **깜짝 상자(D22).** 지난 상자 뒤 2장째부터 15%, 8장 보장(평균 5.5장). 대륙 모양·셋 중 하나 고르기·3등급, 빈 상자 없음, `storage.chest` 버킷.
- **오프라인.** '인터넷 없이 놀기 → 전체 저장하기'에서 국기·그림·음성을 준비한다. 연결이 끊기면 말하기 문제를 같은 나라의 국기 선택 문제로 이어 가고, 누락 그림은 기록 없이 넘길 수 있다. 캐시 네 버킷(`flagquiz-v4` 음원 불변), 누락 자료 이어받기, 내용 기반 셸 버전과 설치 실패 시 이전 셸 보존을 적용했다.
- **이번 변경 검증.** `npm test` 자료·통합 단언 10,028건과 node 테스트 348개(앱 흐름 89건 포함) 통과. `npm run build` 성공, 기본 `npm run verify` 37 통과·0 실패·5 미실행. macOS 브라우저에서 공부 10개 중복 없음·이전 이동·기록 JSON 불변·완료 후 선택, 오답 10개를 제출한 퀴즈도 중복 없는 10개로 종료함을 확인했다. 휴대폰 크기 화면은 390×844에서 확인했으며 실제 아이패드는 미확인이다.

## 그림과 제작 근거

- 최종 WebP **342개, 8,497,504 bytes**, 가장 큰 파일 60,726 bytes. 전부 B 규격 **1024×768**, quality 80, 좌우 12% 여백. 기니 젬베는 19,382 bytes이며 기계 검사 경고·실패 0이다.
- [전체 그림 검수판](../image-prompts/contact/1.html): 40개씩 9페이지. 밝은/어두운 배경과 기존 국기 옆 비교.
- [원장](../image-prompts/presets.json), [제작 기록](../image-prompts/production.json), [실제 생성 요청 387개](../image-prompts/generation-prompts/), [제작 출처](../image-prompts/PROVENANCE.md).
- 원본·native·최종 파일 **1,026개**의 해시와 실제 프롬프트 내용·순서·시도 수를 독립 대조했다. 새 파일이나 수정된 프롬프트가 승인 해시와 다르면 테스트·배포 검사가 실패한다.
- [B 파일럿 검수](../image-prompts/PILOT-REVIEW.md), [앵커 메타데이터](../image-prompts/anchor-review.json). B는 사용자가 확정했으므로 A 8종을 추가 생성하지 않았다. 앵커는 기존 광화문 후보 1장을 검수해 등록했으며, 여러 후보를 비교하거나 생산 전에 기준 그림을 확정한 것처럼 기록하지 않았다.
- 엄격한 원본 배경색 항목은 B 8종 모두 RGB 2~5 정도의 편차·질감 때문에 불일치했다. 전체 64항목 중 56개 통과이며, 이 사실을 감추거나 픽셀 단위 색 일치를 주장하지 않았다. 최종 여백 색은 지정 배경색으로 채웠다.
- 이번 342개는 내장 image_gen의 항목별 독립 호출로 제작했다. 과거를 정규 회차·앵커 재생성 로그로 소급 작성하지 않았으며, 기니의 젬베 생성 요청 3건과 채택·비채택 이력도 원장에 남겼다.
- 실패 원본도 로컬 `docs/artifacts/art-production-2026-09-15/`, `docs/artifacts/art-production-2026-09-17/`와 생성 도구 원본 폴더에 보존했다. Git에는 최종 WebP와 생성 요청·검수 이력을 넣는다.

### 실제 브라우저·오프라인 확인 범위

격리된 Chromium 세션 390×844에서 홈 모드 선택과 실제 정답·오답 클릭을 검증했다. 테스트 서버를 실제 종료한 뒤 새 탭에서 앱·지도·받아 둔 그림·국기를 다시 열었다. 수아 음원은 실제 재생 완료했으며 Range 요청의 206/416도 확인했다. 명소 오답이 기존 국기 기록·오답노트에 들어가지 않았다.

이 검사의 앱 기준은 `e0faf8a`이며, 캐시된 app/quiz/storage/features/map 소스 해시가 당시 primary와 같았다. 후속 도감 조회 수정은 별도 회귀 테스트에서 검사했다. 전체 341장 사전 다운로드나 실제 아이패드 114MB 이관을 시험한 것은 아니다.

## 이 맥의 변환 도구

`sips`와 `/opt/homebrew/bin/cwebp` 1.6.0을 실제 변환에 사용했다. `sips`는 WebP 읽기만 지원하며, ffmpeg·ImageMagick(`magick`/`convert`)은 현재 PATH에 없다. 요청한 명령의 출력:

```text
$ sips --formats | grep -i webp
org.webmproject.webp         webp  
```
