## 이번 T2 보완

- `/images/symbols/`와 `/images/places/`는 하나의 `/images/` 분기로 ART_CACHE만 사용한다. 두 축 모두 200 저장·오프라인 적중, 404 미저장, 다른 버킷 격리, 저장 공간 부족 시 현재 네트워크 응답 보존을 검사했다.
- 독립 검토에서 install 직후 연결이 끊기면 기존 국기를 지운 뒤 예열에 실패하는 경우를 발견했고 테스트에서 재현했다. 기존 국기만 FLAG_CACHE에 먼저 확보하고 성공한 항목의 레거시 원본을 정리하도록 고쳤다. 기존 새 버킷의 응답은 덮어쓰지 않는다.
- 이관 과정에서는 음원을 v4에서 읽거나 복사하지 않고 그대로 둔다. 국기 복사 실패 시 원본을 보존한다. 다만 그 실패한 오프라인 세션에서는 새 국기 버킷에 없는 파일을 사용할 수 없다는 한계가 있다.
- 실제 Chrome에서 최종 워커로 전환 후 네 캐시, 국기 194개, 레거시의 음원만 남는 상태를 확인했다. 국기와 수아 표본의 전후 SHA-256이 같고 오프라인 앱·국기·음원 200 및 Range 206을 확인했다.
