## 그림과 제작 근거

- 최종 WebP **341개, 8,478,122 bytes**, 가장 큰 파일 60,726 bytes. 전부 B 규격 **1024×768**, quality 80, 좌우 12% 여백. 기계 검사 경고·실패 0.
- [전체 그림 검수판](../image-prompts/contact/1.html): 40개씩 9페이지. 밝은/어두운 배경과 기존 국기 옆 비교.
- [원장](../image-prompts/presets.json), [제작 기록](../image-prompts/production.json), [실제 생성 요청 384개](../image-prompts/generation-prompts/), [제작 출처](../image-prompts/PROVENANCE.md).
- 원본·native·최종 파일 **1,023개**의 해시와 과거 재시도 원본 **107쌍**, 실제 프롬프트 내용·순서·시도 수를 독립 대조했다. 새 파일이나 수정된 프롬프트가 승인 해시와 다르면 테스트·배포 검사가 실패한다.
- [B 파일럿 검수](../image-prompts/PILOT-REVIEW.md), [앵커 메타데이터](../image-prompts/anchor-review.json). B는 사용자가 확정했으므로 A 8종을 추가 생성하지 않았다. 앵커는 기존 광화문 후보 1장을 검수해 등록했으며, 여러 후보를 비교하거나 생산 전에 기준 그림을 확정한 것처럼 기록하지 않았다.
- 엄격한 원본 배경색 항목은 B 8종 모두 RGB 2~5 정도의 편차·질감 때문에 불일치했다. 전체 64항목 중 56개 통과이며, 이 사실을 감추거나 픽셀 단위 색 일치를 주장하지 않았다. 최종 여백 색은 지정 배경색으로 채웠다.
- 이번 341개는 내장 image_gen의 항목별 독립 병렬 호출로 제작했다. 과거를 정규 회차·앵커 재생성 로그로 소급 작성하지 않았다. `next/record` 회차 도구는 후속 제작용이며 기존 승인 항목은 `unbatchedApproved`로 보고한다.
- 실패 원본도 로컬 `docs/artifacts/art-production-2026-09-15/`와 생성 도구 원본 폴더에 보존했다. Git에는 최종 WebP와 앵커 PNG 1장, 생성 요청·검수 이력을 넣었다.

### 실제 브라우저·오프라인 확인 범위

격리된 Chromium 세션 390×844에서 홈 모드 선택과 실제 정답·오답 클릭을 검증했다. 테스트 서버를 실제 종료한 뒤 새 탭에서 앱·지도·받아 둔 그림·국기를 다시 열었다. 수아 음원은 실제 재생 완료했으며 Range 요청의 206/416도 확인했다. 명소 오답이 기존 국기 기록·오답노트에 들어가지 않았다.

이 검사의 앱 기준은 `e0faf8a`이며, 캐시된 app/quiz/storage/features/map 소스 해시가 당시 primary와 같았다. 후속 도감 조회 수정은 별도 회귀 테스트에서 검사했다. 전체 341장 사전 다운로드나 실제 아이패드 114MB 이관을 시험한 것은 아니다.

3. 음원 캐시 **`flagquiz-v4`** 유지. activate에서 음원 삭제·복사·재다운로드 없음.
4. 출제 후보와 전체 폴백 모두 자료 있는 나라만 허용. 완화하는 것은 혼동군 배제뿐.
5. 그림은 **`images/symbols/`·`images/places/`**, 국기 194개 SVG는 기존 `flags/` 유지.
6. 새 수아 문구·음원 manifest/config 변경 및 npm 의존성 추가 없음.

과제별 커밋 전에 HANDOFF 금지 6개와 전체 `npm test && npm run verify`를 확인했다. 원격 push 전 `git fetch origin`과 `git pull --rebase origin claude/flag-game-expansion-design-rpv24x`를 실행했고 충돌은 없었다. 로컬 검증과 GitHub CI, main 배포는 서로 별도 상태다.

## 이 맥의 변환 도구

`sips`와 `/opt/homebrew/bin/cwebp` 1.6.0을 실제 변환에 사용했다. `sips`는 WebP 읽기만 지원하며, ffmpeg·ImageMagick(`magick`/`convert`)은 현재 PATH에 없다. 요청한 명령의 출력:

```text
$ sips --formats | grep -i webp
org.webmproject.webp         webp  
```
