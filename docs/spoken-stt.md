# 모든 말하기 놀이의 STT 설계

2026-10-04 설계. 국기 보고 나라 말하기(`voice`), 국기 보고 수도 말하기(`capitalVoice`), 나라 이어 말하기(`country-chain`)를 NAS의 같은 Groq STT로 연결한다. 브라우저 `SpeechRecognition`과 iOS 키보드 받아쓰기 설정에 의존하지 않는다. 읽어주기(TTS)는 기존 Sua 정적 음원을 그대로 사용한다.

## 아이가 답하는 흐름

| 상태 | 화면과 동작 | 말하기 퀴즈 제한시간 |
| --- | --- | --- |
| 마이크 준비 | 로그인·기기 지원을 확인하고 마이크 허용을 기다린다 | 멈춤 |
| 녹음 | “듣고 있어요”를 표시한다. 현재 사람의 답 하나를 받는다 | 실제 녹음 시간 측정 |
| 녹음 정리 | 말소리 뒤 잠깐 조용해지면 녹음을 마친다 | 멈춤 |
| 답 확인 | NAS가 STT 결과를 기다리는 동안 새 녹음을 시작하지 않는다 | 멈춤 |
| 최종 답 선택과 채점 | 현재 문제·세션을 확인하고 문장에서 고른 이름 하나를 기존 채점에 전달한다 | 결과에 따라 진행 |

마이크는 문제 시작과 정답 뒤 다음 문제에서 자동으로 연다. 녹음은 최대 12초이며, 무음만 받으면 유료 전사를 보내지 않는다. 권한·무음·녹음·연결·사용량 오류에는 같은 문제·플레이어 차례·점수·힌트를 유지하고 글자 입력을 펼친다. 아이나 어른이 마이크를 다시 눌러 시도할 수 있으며 실패한 유료 요청은 자동으로 반복하지 않는다. 이름을 판정하지 못한 경우에도 같은 문제에서 다시 답할 수 있다.

제한시간을 켠 판에서는 권한·녹음 정리·전사 대기 시간을 제외한다. 녹음할 때와 같은 문제에서 글자로 답하거나 수동 재시도를 기다릴 때는 기존 남은 시간이 흐른다. 서버 지연 때문에 답을 말한 아이의 시간이 줄어들지 않도록 하면서 수동 입력의 기존 시간 규칙을 유지한다.

최종 인식 문자는 먼저 세 모드가 공유하는 `FQ.spokenAnswer.resolve()`로 해석한다. 모든 나라 또는 수도의 실제 이름·별칭과 정정 표현을 검사하여 `answer`·`retry`·`giveup`을 정한다. 현재 문제의 정답·보기는 이 함수의 입력에 포함하지 않는다. `answer`일 때만 선택한 정식 이름을 `interpret()`·`checkText()` 또는 나라 이어 말하기 matcher로 전달한다. 원문에서 현재 정답과 닮은 이름만 골라 채점하지 않는다.

예를 들어 “뭐지… 스페인 아니고 포르투갈”은 포르투갈, “포르투갈 아니고 스페인”은 스페인이 답이다. “포르투갈인지 스페인인지”·부정만 있는 말·확인 질문·인용은 같은 문제에서 다시 답한다. 단독 도움 요청은 재답변으로 남기고 명시적 “몰라요”·패스는 기존 포기 흐름을 사용한다. 인도네시아의 인도, 기니비사우의 기니처럼 긴 이름의 일부를 별도 답으로 세지 않는다. 짧은 단독 발음만 전체 목록에서 유일한 후보일 때 보완한다. [최종 답 규칙과 Jev 선택 보조](spoken-answer-intent.md)에 문장 예와 해석 한계를 정리했다.

나라·수도 퀴즈는 말소리 뒤 2.2초 침묵을 기다려 짧은 생각의 쉼을 허용한다. 나라 이어 말하기는 기존 1.2초를 유지하며 녹음 상한은 모두 12초다. STT가 만든 중간 문자열은 채점하지 않고 한 녹음의 최종 문장을 해석한다.

정답이면 이름만 짧게 읽고 자동으로 다음 문제로 넘어간다. 읽어주기를 끈 경우에도 기존 짧은 대기 뒤 진행한다. 낭독 완료 이벤트가 누락되거나 재생에 실패한 경우에도 자동 다음 안전장치를 유지한다. 선물은 현재의 작은 알림으로 보여 주고 확인 버튼이나 초점 이동으로 문제를 막지 않는다. 나라 이어 말하기는 인정한 나라 이름을 읽고 상대 차례의 녹음을 이어가며, 중복·여러 나라·모르는 이름은 현재 차례를 유지한다.

## 녹음과 서버 계약

```mermaid
flowchart LR
  A[현재 사람의 짧은 녹음] --> B[브라우저 메모리의 16kHz 단일 채널 WAV]
  B --> C[같은 origin의 NAS API]
  C --> D[세션·Origin·CSRF·중앙 권한·음성 길이·사용량 검사]
  D --> E[Groq STT]
  E --> F[공유 규칙으로 최종 답 선택]
  F --> G[원문·선택 결과·플레이어·차례 식별자]
  F -->|선택 설정과 엄격한 조건 충족| J[최대 3초 Jev 보조]
  J --> G
  G --> H[브라우저 재검증과 정식 이름 채점]
  H --> I[정답 이름 재생과 다음 문제 또는 같은 문제 재답변]
```

- `js/cloud-speech.js`가 `getUserMedia`·`MediaRecorder`로 녹음하고 16kHz·16bit·단일 채널 PCM WAV로 변환한다. API 키와 원본 녹음을 브라우저 저장소에 보관하지 않는다.
- `js/speech.js`가 퀴즈의 시작·상태·결과·오류 콜백과 마이크 수명을 연결한다. TTS나 화면 이동 전에 `stopAnd`·`abort`는 녹음과 전사를 취소한다. 읽어주기 재생 때문에 새로운 유료 전사를 보내지 않는다.
- `js/spoken-answer.js`는 현재 문제 정답을 받지 않는 순수 규칙이다. 서버도 같은 브라우저 소스와 나라·수도 자료를 읽어 사용하며, 브라우저는 선택 결과를 다시 검사하고 정식 이름 하나만 기존 채점에 넣는다.
- `/api/speech`에는 세션 쿠키와 `X-CSRF-Token`, `X-Audio-Duration-Ms`, `X-Speech-Mode`, `X-Player-Id`, `X-Turn-Id`를 보낸다. 서버는 `voice`·`capitalVoice`·`country-chain`만 허용하고 실제 WAV 표본 수로 최대 12초·2MiB를 검사한다.
- 세션·같은 Origin·CSRF·최신 중앙 권한을 확인한 뒤 사용량을 영속 예약하고 Groq `whisper-large-v3-turbo`에 한국어 `ko` 전사를 요청한다. 세 모드는 사용자당 하루 120회·서비스 전체 월 3,000회의 기존 한도를 함께 사용한다. 날짜 경계는 UTC이며 최고 관리자도 같은 한도다.
- 나라 또는 수도 말하기용 짧은 고정 힌트를 사용한다. 현재 문제의 나라·수도 정답과 선택지는 STT에 전달하지 않는다. 플레이어·차례 식별자는 응답의 연결 용도이며 인증이나 사용량의 주체는 서버 세션이다.
- 성공 응답은 STT 원문 `text`와 최종 선택 `resolution`(`status`·`code`·정식 이름 `text`·`reason`·`source`)을 함께 보낸다. 브라우저는 플레이어·차례·화면 세대와 자체 규칙을 재검사한다. 새 문제·새 판·수동 입력·화면 숨김·이동 이후 도착한 이전 응답은 현재 놀이에 적용하지 않는다. 브라우저와 서버는 녹음을 메모리에서 처리하고 앱의 디스크나 학습 기록에 저장하지 않는다.

`server/answer-resolution.mjs`의 Jev 보조는 선택 설정 `TYPESAFE_API_KEY`가 있을 때만 활성화된다. 규칙이 미해석한 복잡한 문장 중 실제 복수 후보와 명시적 최종 선택이 있는 경우에만 `jev-1.13.0`을 최대 3초·전사당 한 번 호출한다. 부정·인용·선택 질문·지시 조작과 단순 나열은 모델 선택으로 덮지 않는다. 미설정·장애·시간 초과·후보 밖 결과는 규칙의 재질문을 유지한다. 현재 키는 연결하지 않았으며 실제 Jev API 응답의 정확도와 운영 호출은 검증하지 않았다. Groq STT와 순수 규칙은 이 키 없이 사용할 수 있다.

요청·전사·취소의 서버 비용 한도와 보관 정책은 [서버 안내](../server/README.md#유료-말하기와-영속-저장)에 있다. 요금 계산은 해당 문서의 2026-10-03 기록을 유지하며 이번 설계에서 변경하지 않는다.

## 연결과 기기 조건

운영 말하기에는 **인터넷·TechJuice ID 로그인·HTTPS·마이크 허용**이 필요하다. 브라우저의 `getUserMedia`·`MediaRecorder`·오디오 변환 지원 여부를 확인하고, 지원하지 않거나 거부되면 같은 문제에서 글자로 답한다. 받아쓰기 활성화 설정을 요구하지 않는다. localhost 정적 `?preview=1`은 인증과 STT를 연결하지 않고 수동 입력으로 놀이를 검토한다.

놀이 중 오프라인이 되면 기존 `continueWithTouch()`를 사용한다. 국기 말하기는 나라 이름과 국기 선택, 수도 말하기는 수도 듣기와 국기 선택으로 바꾸며 같은 문제·차례·점수·힌트·남은 시간을 유지한다. 온라인으로 돌아와도 현재 문제를 바꾸지 않고 다음 음성 문제부터 녹음을 다시 연다. 나라 이어 말하기는 같은 차례의 글자 입력을 제공한다.

보호된 NAS 앱은 인증된 앱 복사본과 음원을 service worker에 저장하지 않는다. 위 전환은 이미 열려 있는 화면에서 연결이 끊긴 경우의 진행 경로이며, NAS 앱을 완전히 오프라인에서 새로 열 수 있다는 뜻은 아니다.

## 검증 범위

[최초 NAS 운영 기록](nas-deploy.md#최초-성공-운영-기록)에는 별도 최초 배포 SHA의 실제 로그인·외부 HTTPS·Groq 전사·운영 백업과 복원·재시작 후 상태 유지가 있다. 합성 대한민국 WAV의 운영 전사 성공은 서버 경로의 증거이며 실제 어린이 마이크 발화 정확도를 증명하지 않는다.

이번 모든 말하기 경로 통합은 별도의 변경이다. 자동 검사는 다음을 확인한다.

1. 세 말하기 모드의 요청·최종 결과 연결, 수도 모드 힌트와 현재 정답 미전달.
   최종 답 선택은 문장 반전·별칭·부분 겹침과 실제 후보를 검사하고, 규칙 밖 문장은 재답변으로 남긴다.
2. 권한·정리·전사 대기 중 제한시간 보존과 녹음 중 시간 측정.
3. 무음·오류·한도·인증 실패에서 같은 문제 유지와 수동 입력·마이크 재시도, 자동 유료 재시도 없음.
4. 수동 답변·홈 이동·숨김·새 문제 이후 늦은 응답 취소, TTS와 녹음 중복 방지.
5. 정답 이름 재생·자동 다음·보상 비차단·마지막 문제의 결과 화면과 오프라인 선택형 전환.

운영 배포 완료는 해당 SHA의 Actions·운영 이미지·외부 로그인 화면·세 모드의 실제 NAS 경로를 별도로 확인한 뒤 기록한다. iPhone/iPad에서 실제 어린이 목소리, 권한 허용·거부·재시도, 나라·수도 인식 정확도와 지연, 두 사람의 연속 차례는 실제 기기 검사로 확인해야 한다. 이 문서 작성 시점에 해당 기기 검사를 완료로 표시하지 않는다.
