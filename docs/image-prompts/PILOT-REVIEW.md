## 4. 내장 image_gen 능력 확인 5항목

| 항목 | 확인값 | 실제 근거와 해석 |
|---|---|---|
| 4:3 출력 `aspect43` | true | 8종 native PNG 모두 1448×1086. 정확히 1024×768로 직접 생성되는지는 별개이며 확인하지 않았다. |
| 참조 이미지 `referenceImage` | true | `referenced_image_paths`에 기존 PNG를 넣어 실제 편집을 실행했다. nl 3기→1기, jm 색 교정 성공. 모든 소재의 스타일 일치를 보장하는 값은 아니다. |
| 시드 고정 `seedLock` | false | 현재 제공된 내장 도구 입력에 seed 인수가 없다. 동일 프롬프트를 반복한 결정성 실험은 미실시다. |
| 네이티브 배치 `batch` | false | 1호출=1자산으로 실행했고 다중 출력 인수가 없다. 별도 호출 4개 병렬 실행은 가능했으나 한 호출의 다중 배치와 다르다. |
| 문맥 오염 `contextBleed` | 미확인/null | 통제된 jp→cn 실험은 하지 않았다. 이번 8종에서 엉뚱한 이전 소재는 보이지 않았으나 일반적 오염 가능성을 false로 확정하지 않는다. |

HANDOFF의 옛 완료 판정은 5개 모두 boolean을 요구하지만, 수행하지 않은 실험을 채우기 위해 값을 만들지 않았다. `contextBleed: null`로 기록한다. bf 흙집과 ve 폭포는 둘 다 실제 생성 결과가 존재한다. 확인한 자료에서는 두 소재의 거절을 발견하지 않았으며, 전체 소재에서 안전 필터 거절이 영원히 없다는 보장은 아니다. 첫 생성이 jp였다는 순서도 소급해 만들어 쓰지 않는다.
