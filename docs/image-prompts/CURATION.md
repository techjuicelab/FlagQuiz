# B 화풍 소재 작성 기록

2026-09-15 사용자가 B 화풍을 선택하고 전체 완성을 요청한 뒤, 상징물 194건과 나라 대표 명소 148건의 영어 피사체 문장을 항목별로 작성했다. 자동 번역 스크립트를 사용하지 않았다.

미주·오세아니아, 아시아, 유럽, 아프리카를 나누어 작성하고 원래 한국어 소재, 고정된 개수, 유사 소재의 색·형태 차이, 아이가 볼 내용과 충돌하는 요소를 교차 검토했다. 공통 B 화풍 문단은 원문 그대로 사용한다. 물·해안·숲 자체가 소재인 항목은 개별 예외에 남겼다.

- `presets.json`의 `koRaw`·`csvStatus`·`riskNote`는 최초 자료를 보존한다.
- `koApprove`는 화면에 쓸 짧은 이름, `subjectEn`은 현재 피사체 명세다. 필드 이름과 달리 보호자가 항목별로 승인했다는 뜻은 아니다.
- `textReview.humanApproval: false`와 `agent-curated`는 에이전트가 검토했음을 나타낸다. 보호자 개별 승인이나 실제 아이패드 검수로 기록하지 않는다.
- `prompts/`는 현재 명세로 재조립할 프롬프트다. 생성·교정에 실제로 보낸 문장은 제작 기록에 따로 보존한다. 교정 후 그림에 맞추어 개수를 정리한 경우에도 과거 요청 문장을 바꾸지 않는다.
- 새 설명 음원을 만들지 않는다. 게임은 기존 나라 이름·나라 설명 음원을 재사용한다.
