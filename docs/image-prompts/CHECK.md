- [ ] 배경은 A #FFFFFF / B #F1F5FB이며, keepsBackdrop 예외를 확인했다.
- [ ] 좌우 12% 여백과 상하 피사체가 변환 뒤에도 보존됐다.

## 기계 항목

포맷·치수·파일 용량·이름·원장 승인 상태·bytes·프롬프트 파일: 스크립트가 봄 (`node scripts/check-images.mjs`).

배포 파일 등록·MIME·서비스워커 버킷: 확장 검사 스크립트가 봄 (`npm run verify`).

기계 검수 통과는 이 사람 검수표를 대신하지 않는다. D-1 실패는 원장의 주제 교체·draft 복귀 사유로 기록한다.
