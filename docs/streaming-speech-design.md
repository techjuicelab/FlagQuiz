# 발화 중 나라·수도 이름 확정

2026-10-06 구현. 실제 공급자 연결과 운영 배포 검증 상태는 이 문서 마지막에 따로 기록한다.

기존 `/api/speech`는 녹음 완료 → WAV 변환 → Groq 전사 → 답 선택 순서이므로 녹음 중 답을 확정할 수 없었다. 새 `/api/speech/stream`은 브라우저 AudioWorklet → 같은 origin의 인증 NAS WebSocket → Soniox `stt-rt-v5` 순서로 말하는 동안 전사를 받는다. 단순히 녹음의 무음 종료 시간을 줄이는 변경이 아니다.

## 이름 확정과 채점

- `non-final` 토큰은 매 응답에서 교체하고 화면에만 표시한다. `final` 토큰만 누적한다.
- 미확정 토큰이 없고 확정된 전체 문자열이 나라·수도 이름 또는 별칭 하나와 정확히 일치하면 즉시 `finishing`을 보낸다. 마이크를 음소거하고 공급자 연결을 닫은 뒤 최신 로그인 상태를 확인해 기존 채점에 전달한다. 현재 문제의 정답은 인식이나 이름 선택에 쓰지 않는다.
- 다른 나라·수도 이름의 앞부분이 되는 “인도”·“기니”·“다카”·“빈”은 조기 확정하지 않는다. `인도네시아` 등 긴 이름의 완성 또는 공급자의 의미적 말끝 `<end>`를 기다린다. 같은 나라의 긴 정식 명칭은 다른 나라로 취급하지 않는다.
- 문장·부정·정정·여러 후보·불완전 발음은 의미적 말끝에서 기존 공유 판정과 Jev 선택을 사용한다. 조기 확정한 이름 뒤에 아직 말하지 않은 정정을 예측할 수는 없다. 이 경로는 이름 하나가 확정되면 답한 것으로 처리하는 짧은 답 정책이다.
- 클라이언트는 800ms 등의 침묵 타이머로 스트리밍 녹음을 끝내지 않는다. 공급자의 endpoint 설정 `max_endpoint_delay_ms:500`은 고정 녹음 시간이 아니다. 수동 멈춤과 12초 안전 상한에서만 `finalize`를 한 번 보낸다.

## 입력과 수명

세 모드 `voice`, `capitalVoice`, `country-chain`은 공통 엔진을 쓴다. 서버가 로그인 응답에 `speechStreaming:true`를 주고 브라우저가 AudioWorklet을 지원할 때 스트리밍을 선택한다. 설정 또는 기기 지원이 없으면 기존 Groq 파일 경로를 선택한다. 유료 요청을 시작한 뒤 실패를 다른 유료 공급자로 자동 재시도하지 않는다.

AudioWorklet은 44.1/48kHz 입력을 상태를 유지하며 16kHz mono PCM16, 100ms 프레임으로 변환한다. 준비 비프와 TTS 동안 트랙과 송신을 음소거한다. 클라이언트는 실제 말소리 100ms 이후 400ms pre-roll부터 보내고, 서버도 실제 말소리 100ms(최대 80ms의 짧은 공백 허용)를 독립 검사한 뒤에만 사용량을 예약하고 공급자에 연결한다. 따라서 무음 대기와 짧은 클릭에는 공급자 연결과 사용량 예약이 없다. RMS 기준은 말소리와 모든 종류의 배경음을 완전히 구별하지 못한다.

서버가 확정 이름을 고르면 `finishing` → `result` 순서로 보낸다. `finishing`은 입력을 즉시 멈추며, 최종 인증·답 선택 대기에 추가 오디오를 보내지 않는다. `stop()`은 최종 결과를 기다리고 `cancel()`은 결과를 폐기한다. `cancel({keepMicrophone:true})`는 음소거한 마이크만 다음 차례에 재사용한다. 화면 이동·숨김·글자 입력·힌트·TTS·새 판은 기존 세대/차례 취소 규칙을 유지한다.

## 인증·비용·배포

쿠키와 정확한 Origin으로 WebSocket을 열고 첫 작은 JSON에서 CSRF·모드·플레이어·차례를 확인한다. 공급자 키와 모델 설정은 서버에만 있고 URL·브라우저·로그에 넣지 않는다. 유료 연결 직전과 최종 결과 직전에 같은 세션·최신 중앙 권한을 다시 확인한다. 파일 전사와 스트리밍은 사용자 일일 120회·전체 월 3,000회·사용자 동시 1개·전체 동시 4개의 한도를 공유한다. 취소·실패한 유료 예약은 돌려주지 않는다.

PCM 길이 최대 12초, 프레임 8KiB, 송수신 대기 64KiB, 인증 메시지 대기·무음 대기·공급자 연결 시간과 전체 연결 수에 상한을 둔다. Soniox는 연결 전체 시간을 과금하므로 확정·취소·실패 후 연결을 닫는다. 오디오와 전사는 디스크에 저장하지 않는다. 세션·쿼터 데이터 형식과 기존 볼륨은 유지한다.

`SONIOX_API_KEY`는 `env/private.op.env`의 1Password ID 참조에서 주입하고 Forgejo `APP_ENV_FILE`에 배포 사본을 동기화한다. Compose는 web에만 전달하며 백업에는 키를 주지 않는다. 새 `ws` 의존성은 lockfile과 `npm ci --omit=dev --ignore-scripts`로 설치하고 운영 이미지에도 포함한다.

## 검증 상태

일반 Chrome의 실제 AudioContext·AudioWorklet·인증 WebSocket과 한국어 합성 WAV를 사용한 세 모드 통합 검사에서, 가짜 공급자 응답 직후 녹음 중단·트랙 음소거·한 번 결과 전달·해제를 확인했다. 이 검사는 실제 Soniox 인식 정확도나 지연 측정이 아니다. Ego 검증 브라우저에서는 같은 Worklet 로딩이 멈췄고 일반 Chrome에서는 정상 로딩됐다. 이 과정에서 발견한 미완료 Worklet의 마이크 해제 누락과 잘못된 권한 오류 표시를 수정했다. 실제 공급자 키 조회는 1Password 인증 만료로 대기 중이며, 실제 한국어 전사·운영 이미지 확인 전에는 실제 기기에서 해결됐다고 표시하지 않는다. 기존 run595/126adcc 배포의 Groq 전사 성공은 새 스트리밍 연결의 성공 증거로 사용하지 않는다.

iPhone/iPad 실제 어린이 목소리, Safari/홈화면 마이크 권한과 두 사람 연속 차례 검사는 실제 기기에서 별도로 확인한다.
