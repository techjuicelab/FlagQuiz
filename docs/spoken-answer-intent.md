# 말한 문장에서 최종 답 찾기

세 말하기 모드(`voice`, `capitalVoice`, `country-chain`)는 녹음 → NAS STT → 최종 답 선택 → 기존 채점 순서를 사용한다. STT는 글자를 만드는 역할이고, 이 단계는 아이가 그 문장에서 무엇을 답으로 골랐는지를 찾는다.

- `뭐지… 음… 스페인 아니고 포르투갈` → 포르투갈을 채점한다.
- `포르투갈 아니고 스페인` → 스페인을 채점한다. 문제 정답이 포르투갈이어도 포르투갈로 바꾸지 않는다.
- `포르투갈인지 스페인인지`·부정만 있는 말·확인 질문·다른 사람의 말 인용 → 점수와 차례를 유지하고 하나의 답을 다시 말하도록 안내한다.
- 명시적 포기는 기존 “몰라요” 흐름을 사용한다. 앞에서 도움을 요청했다가 뒤에서 답을 고르면 답이 우선한다.

`js/spoken-answer.js`는 모든 나라 또는 수도의 이름·별칭을 검사한다. 인도/인도네시아, 기니/기니비사우처럼 긴 이름 안의 짧은 이름을 별도 답으로 세지 않는다. 문장에 나온 이름과 정정 표현으로 최종 직접 선택을 찾으며 현재 문제·정답·보기는 입력으로 받지 않는다. 일반 문장 속 임의의 낱말에 느슨한 이름 판정을 적용하지 않는다. 짧은 단독 답의 기존 발음 허용도 전체 목록에서 유일한 후보일 때만 사용한다.

나라·수도 문제는 발화 뒤 2.2초 침묵을 기다려 짧은 생각의 쉼을 허용한다. 나라 이어 말하기는 1.2초를 유지하며 녹음 상한은 12초다. 상한 이후의 발화나 침묵보다 긴 간격으로 이어진 말까지 한 녹음으로 묶는 것은 보장하지 않는다. 정답을 맞히면 이름을 읽고 다음 문제로 진행한다. 미인식과 미선택에는 같은 문제에서 수동으로 마이크를 다시 누르거나 글자로 답한다.

## Jev 선택 보조

[TypeSafe의 후보 추출·선택 방식](https://docs.typesafe.ai/cookbooks/pre_parsed_value_extraction_cookbook)에 따라 코드가 먼저 실제 발화의 후보를 찾는다. 규칙이 명확히 해석한 답은 바로 사용한다. 복잡하지만 명시적 최종 자기 선택이 있는 문장에 한해서 서버가 Jev `Choice`에 후보와 `unresolved`/`giveup`을 보낸다. 출제 정답·사진·보기·아이 이름·계정은 보내지 않는다. 모델이 말하지 않은 나라를 추론하거나 채점을 직접 결정하지 못하도록 반환 코드를 실제 후보와 다시 대조한다.

`server/answer-resolution.mjs`는 `jev-1.13.0`을 고정 사용한다. 최대 3초, 전사 한 번당 최대 한 번 호출하고 자동 재시도하지 않는다. 부정·인용·선택 미정·판정기를 조작하는 명령은 모델 선택으로 덮지 않는다. 미설정 키, 장애, 시간 초과, 잘못된 형식, 후보 밖 결과 또는 보수적 기준 미달은 규칙의 재질문 결과를 유지한다.

`TYPESAFE_API_KEY`는 서버의 선택 설정이며 기본값은 비어 있다. 키 값은 서버 실행 시 1Password에서 주입한다. 브라우저·빌드 결과·로그·학습 기록에는 저장하지 않는다. 기존 배포 설정에 이 키가 없으면 규칙 판정만 동작한다. 서버에 키를 연결하기 전에도 모든 STT 모드는 사용할 수 있다.

현재 기준은 `confidence >= 0.9`, 선택 확률 `>= 0.95`, 다음 후보와 차이 `>= 0.8`이다. 이 수치는 도메인 정확도를 보장하는 값이 아니다. 공식 문서에 따르면 [confidence는 선택 확률 분포의 집중도](https://docs.typesafe.ai/confidence)이며, [CJK 지원의 정확도 한계](https://docs.typesafe.ai/models#language-support)와 [적대적 입력·선택지 순서 한계](https://docs.typesafe.ai/model-jaggedness/jev-1.13)가 있다. 실제 한국어 어린이 전사와 정답표를 사용해 오정답 인정률·불필요한 재질문율·지연을 따로 측정해야 한다.

## 확인 범위

자동 검사에서는 규칙의 문장 반전·부정·인용·미정·수도·별칭, 모델 응답 형식·임계·후보 밖 결과·취소·장애, 앱의 점수/문제/차례 유지와 자동 다음을 확인한다. 합성 브라우저 마이크는 실제 인증·녹음 처리·HTTP 전송·최종 채점 흐름을 검사하는 도구이며 실제 iPhone 마이크나 어린이 발화 정확도 검증을 대신하지 않는다. 실제 Jev 응답의 정확도는 API 키를 연결하고 별도로 비교하기 전까지 검증 완료로 표시하지 않는다.
