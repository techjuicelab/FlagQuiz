# 최신 NAS 앱 오프라인 점검 · 2026-10-09

## 확인한 문제와 수정

기존 공개 앱에는 오프라인 저장이 있었지만, NAS 전환 뒤에는 홈·설정의 저장 UI를 숨기고 NAS 전용 워커가 앱 캐시를 모두 삭제했다. 로그인 확인도 서버 연결 실패에서 시작을 차단해 최근 버전은 오프라인 재실행이 불가능했다.

로그인한 기기에서 빌드된 최신 셸과 국기·그림·읽어주기·음악을 저장하도록 복구했다. 설치 아이콘 512px·maskable 512px 누락도 보완했다. 빌드에서 워커 설치 목록의 모든 파일을 확인하며, 보호 모드 설정까지 셸 버전 해시에 포함한다.

서버에서 실제 확인한 세션의 만료기한 안에서만 저장본을 연다. 저장하는 허용 정보는 `authenticated`, `offline`, `expiresAt`뿐이다. 이메일·관리자 역할·CSRF·음성 API 응답을 저장하지 않으며, 서버가 인증을 거절했을 때 캐시로 우회하지 않는다. 만료·로그아웃·접근 해제 시 앱 캐시를 지우고 열려 있는 다른 창에도 알린다. 오프라인 로그아웃은 기기 접근을 즉시 차단하고 재연결 후 서버 세션도 폐기한다. 다른 기기에서의 권한 회수는 다음 온라인 확인 때 반영된다.

2026-10-09 점검 당시 클라우드 음성 인식은 Soniox/Groq를 사용했다. 2026-10-15부터 실시간·녹음 후 경로 모두 Soniox 실시간 모델을 사용하며, Soniox 인식·Jev 서버 판정에는 인터넷이 필요하다. 녹음 후 경로도 WAV를 서버 메모리에서 PCM으로 읽어 전송하며 공급자 파일 업로드·비동기 전사 리소스는 생성하지 않는다. 국기·수도 말하기는 같은 문제·점수의 선택 입력으로, 나라 이어 말하기는 같은 차례·찾은 나라의 글자 입력으로 계속한다. 최근 아이 발음·정정 표현의 로컬 이름 판정은 오프라인에서도 사용한다. 이는 전사 뒤 이름을 해석하는 규칙이며 기기 내 STT 모델을 뜻하지 않는다. 브라우저가 온라인으로 표시되어도 서버 연결에 실패해 저장 세션으로 열린 경우에는 마이크·소켓·업로드를 시작하지 않는다.

읽어주는 나라·수도·힌트는 미리 생성한 Typecast Sua MP3 1,319개다. 전체 저장 기능으로 받은 음원을 반복 재생하며 Soniox TTS 요청을 생성하지 않는다. STT 요청에 붙이던 문맥 사전은 별도의 텍스트 입력이므로, 음원 캐시와 구분한다. 현재 Soniox 실시간·녹음 후 전사 모두 문맥 사전과 고정 프롬프트를 보내지 않는다.

## 실제 Chromium 브라우저 검사

유료 공급자·실제 사용자 정보 없이, 실제 NAS 인증 서버 코드와 전체 배포 파일을 사용한 로컬 테스트 서버에서 검사했다. 온라인 로그인 → 전체 저장 → 워커 업데이트 → **테스트 서버 완전 종료** → 앱 재실행 순서이며, 요청 실패를 단순 모사한 검사와 구분한다.

- 전체 1,918개 자료 저장 뒤 셸 업데이트에도 기존 국기·그림·음악·읽어주기 캐시를 유지하고 `준비 완료` 확인.
- 서버 종료 후 저장 세션으로 홈 재실행 성공.
- 9개 퀴즈 화면에서 답 입력 가능, 국기·그림 모두 실제 이미지 로드 성공, 두 말하기 모드는 마이크 없이 선택 문제 제공.
- 나라 이어 말하기의 마이크 차단·글자 입력·다음 차례 전환·지도·국기 표시 성공.
- 오프라인 정답 1회 기록 후 앱 재실행에서도 기록 유지.
- Sua `대한민국` 읽어주기 재생 종료 콜백 확인. 음원 Range 요청 `206`, 100바이트 응답 확인. 음악 디코딩 성공.
- 오프라인 로그아웃 후 앱 캐시 0개·보호 파일 재요청 실패·학습 기록 유지. 서버 재시작 후 로그아웃 예약 해제 및 실제 서버 세션 미인증 확인.

로컬 JSON 증거는 무시되는 `docs/artifacts/offline-2026-10-09/`에 보관한다. 실제 iPhone/iPad Safari 홈 화면 앱의 비행기 모드, 기기 저장 공간 정리 정책과 물리 스피커 체감 음량은 이 Chromium 검사로 대신 확인했다고 주장하지 않는다.

## 이용 방법

실제로 사용할 브라우저 또는 홈 화면 앱에서 온라인으로 로그인한 뒤 **설정 → 오프라인 저장 → 전체 저장하기**를 누르고 **준비 완료**를 확인한다. 저장 중 닫거나 연결이 끊겨도 받은 자료를 유지하며, 다시 열고 서버 연결을 확인하면 요청했던 전체 저장을 이어받는다. 로그인 만료 후에는 온라인 재로그인이 필요하다.
