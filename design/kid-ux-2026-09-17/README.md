# 아이 기준 화면 개선 시안 (2026-09-17)

만 4~5세 아이가 혼자 쓰는 것을 기준으로 아이폰(390×844)·아이패드 가로(1180×820)·아이패드 세로(820×1180) 화면 14장을 그린 디자인 캔버스 원본이다.
캔버스: https://claude.ai/artifact/ET5Mre42b6RKY63eodDGGb (Design Component `.dc.html` + `canvas.json`).

- 그림 속 국기·삽화는 캔버스 자산 저장소의 `/_blob/<id>` 주소를 가리키므로 저장소에서 바로 열면 이미지가 비어 보인다. 캔버스에서 보거나, `flags/`·`images/` 의 같은 파일로 바꿔 열면 된다.
- `Main.dc.html` 은 아이폰 홈이다(캔버스 진입 아트보드).
- 다섯 가지 원칙: 첫 화면은 큰 놀이 단추 4개만 · 글자 대신 소리 · 보기는 국기가 주인공 · 처음 만나는 나라는 만나기 카드 먼저 · 모든 화면은 스크롤 없이 한 화면(손가락 목표 44px 이상).
