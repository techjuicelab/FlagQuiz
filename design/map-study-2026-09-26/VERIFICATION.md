# 지도 공부·퀴즈 개선 검증

2026-09-26 사용자 요청: 지도 공부와 퀴즈를 분리하고, iPhone/iPad에서 지도를 크게 보며 대륙과 나라의 실제 위치를 이해할 수 있도록 한다.

## 변경 내용

- 지도 메뉴에서 공부·퀴즈를 각각 선택한다. 공부는 무채점이며 이전/다음/다른 나라 묶음을 제공한다. 퀴즈는 한 판에 나라를 반복 출제하지 않는다.
- 세계지도에 대륙 이름을 표시한다. 공부와 정답 화면에서는 세계 위치, 주변 확대 지도, 나라의 대표 위치 점, 확대 범위를 함께 표시한다.
- 기존 Natural Earth 육지와 194개 나라의 대표 좌표를 같은 투영으로 사용한다. 지형 비율은 세계 2:1, 지역 4:3으로 보존하며 날짜변경선 주변은 지형을 이어 붙인다.
- 큰 번호와 실제 위치 점을 분리하고 터치 영역은 44px로 유지한다. 대륙 이름표가 위치를 가리면 이름표만 옮긴다.
- 퀴즈는 전체 폭으로 배치한다. 899px 이하에서는 지도 확대/세계 전체 보기와 좌우 스크롤을 제공한다.
- 지도 정답 화면은 설명의 시작부터 보여 준다. 보상 상자를 닫을 때 자동 스크롤로 지도를 건너뛰지 않는다.

지도는 나라의 면적·국경을 표시하는 정치 지도가 아니다. 화면에서도 점이 나라의 대표 위치라는 점을 명시한다. 원자료를 손으로 변경하거나 외부 지도 라이브러리·새 음원을 추가하지 않았다.

## 자동 검사

- `npm test`: 통합 10,028건 + Node 361건 통과. 앱 흐름 내부 96건 포함.
- `npm run build`: 음원 1,319개·음악 16개를 포함한 배포 묶음 생성 성공.
- `npm run verify`: 37통과·0실패, 기존 원자료/심화 검사 5개 미실행.
- `git diff --check`: 통과.

지도 좌표 역투영, 194개 나라의 범위, 날짜변경선, 독립 공부의 기록 보존, 늦은 음성 콜백, 반복 없는 퀴즈, 확대 시 채점·좌표 보존을 회귀 검사한다.

## 브라우저 검사

Ego Lite의 Chromium에서 화면 크기를 모의 검증했다. 실제 iPhone/iPad Safari 검증은 포함하지 않는다.

- 390×844 공부: 세계 324×162, 지역 324×243. 가로 넘침 없음.
- 1366×1024 퀴즈: 지도 1250×625, 한 열 배치, 모든 핀 44×44. 공부는 세계·지역 지도를 나란히 배치한다.
- 320×740 퀴즈: 긴 나라 이름과 정답 설명이 가로로 넘치지 않는다. 지도 확대 시 248×124에서 540×270으로 확대되며 문서는 가로로 넘치지 않는다.
- 320/390/820/1180/1366px에서 퀴즈·확대·공부 13개 화면 조합: 가로 넘침 없음. 820px 확대 지도는 1484px이며 내부에서만 좌우로 움직인다.
- 밝은 화면·다크 모드와 노르웨이의 대륙 이름표 겹침 보완을 캡처로 확인했다.
- 지도 정답 선택 후 초점은 `feedback-area`로 이동하며 지도 설명 시작을 표시한다.

검증 스크린샷·배포 해시 결과는 무시되는 `docs/artifacts/map-study/`, `docs/artifacts/deploy/`에 보관하며 배포 파일에는 포함하지 않는다.

## 오프라인 검증

- 로컬 서버를 종료하고 캐시만으로 앱을 재실행했다. 네트워크 오프라인 상태에서 지도 공부의 세계·지역 지도 2개와 국기 이미지를 표시했다.
- 나라 설명 듣기를 눌러 저장된 음원의 실제 재생 시간이 0.111초를 넘는 것을 확인했고 해당 음원이 캐시에 있음을 확인했다.
- 다음 나라 이동, 메뉴 복귀, 퀴즈 시작, 지도 확대까지 진행했다. 공부 전후 설정을 제외한 전체 기록이 동일했다.
- 기존 미디어 캐시 유지: 국기 194개, 그림 버킷 343개, 오디오 1,335개. 그림 버킷은 기존 추가 항목을 포함하므로 배포 그림 파일 342장과 구분한다.
- 이 검증용 브라우저 작업 공간을 종료했다. 실기기 비행기 모드 검증을 수행했다는 뜻은 아니다.
