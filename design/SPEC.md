# 세계 국기 퀴즈 — 게임형 리디자인 아트보드 사양

너는 이미 배포되어 돌아가는 어린이용 학습 게임의 **게임형 리디자인 시안**을 그린다.
결과물은 Design Component 형식의 `.dc.html` 파일 **한 개**다.

## 이 앱이 무엇인지

- 한국어 어린이용(7~10세) 세계 국기 퀴즈. 부모(아빠)와 아이(민규)가 함께 한다.
- 194개국. 놀이 방식 5가지: 국기→나라 사지선다 / 나라→국기 찾기 / 말로 답하기(마이크) /
  이름 써서 맞히기 / 수도 맞히기. 2인 번갈아 대결도 있다.
- 지금은 "학습 앱" 느낌이 강하다. 이번 시안의 목표는 **게임처럼 재미있게**,
  **애니메이션이 풍부하게**, 그리고 **모은다는 보상 체계**를 갖추는 것이다.

## 이 앱의 시각 어휘 (따라야 함)

- **이모지를 쓴다.** 기존 앱이 🚩🎤⌨️🏙️🔥⭐🎉 를 쓰고 있고 아이용이라 어울린다.
  단 **UI 아이콘(체크·자물쇠·화살표·톱니 등)은 이모지 대신 인라인 SVG**로 그린다
  (stroke 기반, 20/24px 격자, 굵기 2, 한 가지 스타일로 통일).
- 카드 + 부드러운 그림자 + 넉넉한 둥근 모서리. 밝고 경쾌하게.
- 그라데이션은 단추·보상 같은 **작은 면적에만**. 화면 전체를 그라데이션으로 덮지 마라.

## 애니메이션 (이번 시안의 핵심)

- 순수 CSS `@keyframes` 로만 만든다. 자바스크립트를 쓰지 마라.
- **아트보드를 열면 바로 눈에 보여야 한다.** 등장 애니메이션(들어오기)과
  계속 도는 애니메이션(반짝임·둥둥·맥박)을 섞는다.
- 순차 등장은 `animation-delay` 를 요소마다 조금씩 다르게 주어 만든다.
- 반드시 넣을 것:
  ```css
  @media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }
  ```
- 과하지 않게. 한 화면에 "주인공 동작" 하나 + 거드는 작은 동작 몇 개.

## 파일 형식 (Design Component) — 정확히 이 뼈대를 지켜라

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
  <style>
    /* 전역 CSS, @keyframes, @font-face, prefers-reduced-motion 은 여기 */
  </style>
</helmet>
<div style="...">
  <!-- 실제 디자인. 뷰어가 색·간격을 고칠 수 있게 style="..." 인라인으로 쓴다 -->
</div>
</x-dc>
</body>
</html>
```

절대 규칙
1. `<script src="./support.js"></script>` 줄을 **글자 하나도 바꾸지 마라.** 지우거나 인라인화 금지.
2. `<x-dc>` 안에 **최상위 요소 하나**만 두고 그 안에서 구성한다.
3. **`<script data-dc-script>` 블록을 넣지 마라.** 이 아트보드들은 전부 정적이다.
   `{{ }}` 구멍, `<sc-for>`, `<sc-if>`, `<dc-import>` 도 쓰지 마라.
4. 모든 태그를 닫고, 모든 속성값을 겹따옴표로 감싼다.
5. 나란한 것들(단추 묶음, 칩, 카드 줄)은 `display: flex` 또는 `display: grid` + `gap` 으로 배치한다.
   여백을 공백 문자나 요소별 margin 으로 만들지 마라.
6. 이미지 파일을 참조하지 마라. 국기는 **CSS 도형(그라데이션·네모·동그라미)** 으로 그린다.
   예: 일본 = 하얀 네모 + 빨간 동그라미, 캐나다 = 빨강·하양·빨강 세로 3칸.
7. 링크(`a`)를 쓰면 `<helmet><style>` 에 색과 hover 색을 정의한다.
8. 글은 전부 **한국어**, 아이 눈높이 존댓말. lorem ipsum 금지. 실제로 쓸 만한 문구로 쓴다.
9. 가짜 아이폰 상태바(9:41·배터리·와이파이)나 가짜 자판을 그리지 마라.

## 보상 체계 (모든 아트보드가 같은 체계를 쓴다)

- **별(⭐)** — 한 판 성적. 정답률 90%↑ 3개, 70%↑ 2개, 40%↑ 1개.
- **경험치와 레벨** — 문제를 맞히면 경험치가 오르고 레벨이 올라간다. 레벨 이름은
  `씨앗 탐험가 → 새싹 탐험가 → 나침반 탐험가 → 지도 박사 → 세계 박사`.
- **스티커** — 나라를 처음 맞히면 그 나라 스티커를 얻는다. 194칸을 채우는 것이 장기 목표.
- **보물상자** — 5문제 연속 정답이나 하루 도전 완료 때 열린다. 안에서 스티커·별·꾸미기가 나온다.
- **불꽃 콤보(🔥)** — 연속 정답. 3·5·7연속에서 단계가 올라간다.
- **하루 도전** — "오늘은 아프리카 5문제" 같은 작은 목표.

숫자는 그럴듯한 예시 값을 쓴다(민규, 레벨 4, 스티커 63/194 등). 모든 아트보드가 **같은 예시 값**을 쓴다:
플레이어 이름 **민규**, 레벨 **4 (나침반 탐험가)**, 경험치 **340/500**, 스티커 **63/194**,
별 **17개**, 최고 콤보 **9연속**, 오늘 도전 **아프리카 5문제 중 3개**.
