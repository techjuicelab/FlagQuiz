# UI 개편 검증

검증일: 2026-09-26. 기준은 사용자 승인 계획 `PLAN.md`이며, 출제·채점·저장소 구조와 미디어 파일은 변경하지 않았다.

## 자동 검증

- `npm test`: 통합 검사 10,028건, Node 검사 357건 통과. 앱 흐름 내부 검사 91건 포함.
- `npm run build`: Sua 음원 1,319개·음악 16개·국기 194장·그림 342장의 배포 묶음 생성 성공.
- `npm run verify`: 37통과·0실패. 기존 원본 자료/깊은 검사 등 5개는 실행하지 않았다.
- `git diff --check`: 통과.
- 설정 일반 클릭, 즉시 저장, 입력·선택·포커스·스크롤 유지, 지원하지 않는 옵션의 저장값 보존을 검사했다.
- 국기 4방식·그림 2방식·지도·수도 2방식, 수도 공부 분리, 화면 이동 시 음성·마이크·자동 다음 예약 정리 검사를 유지했다.
- 초기화 확인 취소 시 기록 보존, 안전한 JSON 내보내기, 대륙별 수집 및 도감 이동을 검사했다.
- 설정을 닫거나 홈 요약을 재생성해도 진행 중인 다운로드 요청·진행률이 유지되는지 검사했다.

## 브라우저 화면과 조작

Ego Lite의 Chromium 화면 크기 모의 검증이다. 실제 iPhone/iPad Safari 또는 설치 앱의 기기 검증으로 간주하지 않는다.

- 320×568, 390×844, 507×768, 820×1180, 1180×820에서 홈·설정·도감·기록 20개 조합: 문서 가로 넘침 없음. 도감 대륙 필터는 내부 가로 스크롤을 유지한다.
- 같은 5개 크기에서 국기 선택·역방향·입력·그림·명소·지도·수도 35개 조합: 문서 가로 넘침 없음, 퀴즈 중 주요 내비게이션 숨김.
- 320/507/1180px에서 본문 200% 확대, 홈·설정·도감·기록·수도 15개 조합: 문서 가로 넘침 없음. 세로 스크롤로 모든 내용에 접근한다.
- 밝은 화면·다크 모드·동작 줄이기 확인. 설정 스위치 실제 조작 영역 49×44px.
- 설정 버튼 Enter·Space 진입, 문제→피드백→결과 이동 확인.
- 휴대폰 홈·설정·수도·피드백·결과, iPad 홈·수도, 다크 화면을 캡처해 직접 검토했다.

## 기존 기록과 캐시

- 개편 전 앱의 기록을 유지한 채 새 서비스 워커로 갱신했다. 갱신 전후 `settings`, `stats`, `countries`, `axes`, `badges`, `history`, `chest`, `daily`가 모두 동일했다. 이후 QA에서 푼 문제는 정상적으로 같은 저장소에 추가됐다.
- 기존 미디어 버킷 이름을 유지했다. 갱신 전후 캐시 항목 수는 국기 194, 그림 버킷 343, 오디오 1,335로 동일했다. 그림 버킷 항목 수는 기존 추가 항목을 포함하며 배포 그림 파일 수 342와 구분한다.
- 국기·그림·오디오 각 2개, 총 6개 캐시 응답의 SHA-256이 갱신 전후 동일했다. 변경된 셸만 콘텐츠 해시로 갱신했다.
- 로컬 서버를 종료한 뒤 앱을 재실행했다. 캐시에서 브라질 그림을 표시했고, 듣기 버튼을 눌러 실제 오디오의 `currentTime > 0.1` 조건을 통과한 뒤 화면을 캡처했다.
- 마지막 음성 모드 전환의 브라우저 모의 검증은 마이크 권한 창으로 중단됐다. 실제 오프라인 이벤트에서 같은 문제를 터치 답변으로 전환하는 기존 자동 회귀 검사는 통과했다. 실제 기기의 마이크 권한·네트워크 전환 확인은 별도다.

검증 캡처와 로컬 로그는 배포 파일에 포함하지 않는다. GitHub Pages 배포는 main 커밋의 CI 성공과 공개 자산 해시 일치로 별도 확인한다.
